# Уведомления о новых заявках

## Что происходит сейчас

- Формы «Предложить игру», «Предложить помощь» и баг-репорта создают публичные GitHub Issues и автоматически назначают их владельцу репозитория, чтобы GitHub прислал ему уведомление.
- Готовую игру предлагают Pull Request; после проверки и принятия PR GitHub Pages публикует изменения.
- Google Sheet «Games — сообщество разработчиков» — отдельный ручной трекер. Он пока не синхронизируется с GitHub и сам по себе не получает новые Issues/PR.

## Получать уведомления на почту

Чтобы GitHub присылал уведомления о новых предложениях и PR на нужный адрес:

1. В GitHub открой **Settings → Emails**, добавь нужный адрес и подтверди его, если его там ещё нет.
2. В **Settings → Notifications → Email notifications** выбери подтверждённый адрес для уведомлений.
3. На странице репозитория `m98978672-boop/games` нажми **Watch → Custom**, включи **Issues** и **Pull requests**, затем сохрани настройки.

GitHub будет отправлять уведомления при появлении новых обращений и PR. Сам сайт не отправляет почту из браузера: для этого потребовался бы отдельный backend и защищённые учётные данные.

## Уведомления в Google Sheets

В Google Sheets можно открыть **Tools → Notification settings → Edit notification settings** и выбрать **Any changes are made → Email right away**. Google отправит такие уведомления на адрес Google-аккаунта, который владеет таблицей/настроил правило; из таблицы нельзя задать произвольный адрес получателя без дополнительного Apps Script.

Важно: пока новые GitHub Issues/PR не добавляются в таблицу автоматически. Чтобы сделать двустороннюю синхронизацию, нужен отдельно настроенный интеграционный endpoint и доступ к таблице. Не размещайте токены или пароли в HTML/JavaScript сайта.
