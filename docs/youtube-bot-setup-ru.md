# Подключение YouTube-канала к боту

В репозитории теперь есть первая версия панели `youtube-bot/`: она подключается к одному каналу, принимает готовый видеофайл, загружает его на YouTube как приватный и задаёт будущее время публикации. Генерация роликов, выбор тем и управление комментариями пока не реализованы.

## Что делать дальше

1. Создайте OAuth-клиент Google Cloud, следуя разделу **«1. Создайте OAuth-клиент Google»** в [`youtube-bot/README.md`](../youtube-bot/README.md).
2. При создании клиента добавьте redirect URI точно такой: `http://localhost:8765/oauth2callback`.
3. Скачайте OAuth JSON и положите его как `youtube-bot/client_secret.json`. **Не отправляйте его в чат и не добавляйте в Git.**
4. Установите зависимости и запустите локально — команды есть в разделе **«2. Запустите локально»** того же README.
5. Откройте [http://localhost:8765](http://localhost:8765), подключите Google-аккаунт, проверьте название канала и сначала протестируйте публикацию на коротком видео, права на которое у вас есть.

## Важное

- Используйте именно тот Google-аккаунт, которому принадлежит канал. На странице авторизации Google самостоятельно выберите аккаунт и подтвердите разрешения.
- Приложение работает локально на вашем компьютере; пока сервер работает, оно может отправить загруженное видео и расписание в YouTube. После того как YouTube принял расписание, публикация хранится на стороне YouTube.
- Не открывайте этот MVP напрямую в интернет: в нём ещё нет отдельной авторизации пользователей и защиты для публичного сервера. Для постоянной работы в облаке сначала нужно добавить защиту доступа, HTTPS, безопасное хранение OAuth-токенов и настройку публичного callback URL.
- Не присылайте пароли, коды подтверждения, OAuth client secret, токены или JSON-файлы. Если Google покажет ошибку, пришлите только текст ошибки без секретных данных.

Подробные команды, официальные Google-ссылки и ограничения первой версии: [`youtube-bot/README.md`](../youtube-bot/README.md).
