# «Похождения Балтики 0» — пролог

Готовый вертикальный мультфильм-пролог о приключениях ожившей банки «Балтика 0».

- **Видео:** `baltika-0-prologue.mp4` — 1:13, вертикальный H.264 720×1280, 24 fps.
- **Обложка каталога:** `site-thumb.jpg` — промо-кадр, используемый в `boris/videos.js`.
- **Сценарий / раскадровка:** `script.md`
- **Реплики:** только диалоги персонажей — мужика, друга и Балтики 0. Диктора нет; у каждого говорящего персонажа отдельный голос.
- **Музыка:** `audio/original-meme-score.wav`, оригинальная процедурная подложка для этого ролика, без заимствованной мелодии.
- **Диалоговая дорожка отдельно:** `audio/dialogue-track.wav`.
- **Визуальный стиль:** оригинальная 2D-векторная мульт-анимация с титрами и встроенными субтитрами; Балтика 0 — главный персонаж и источник повторяющихся шуток.
- **Ненавязчивая визуальная деталь:** маленькая фоновая пиктограмма «бутылка + ослабленный пульс» и ровная линия-сердце на банке 0.0; без озвученной морали и явного лозунга.

Сюжет намеренно фантастический и сатирический. Табличка «ТЦК — Территориальный центр кеглей», ожившие банки и экспедиция к холодильнику — вымысел, не документальная съёмка и не утверждение о реальных событиях.

## Пересборка

```bash
python3 -m pip install -r requirements.txt
python3 render.py
```

Рендер создаёт MP4 в этой папке и отдельные WAV дорожки в `audio/`. Исходные генерируемые реплики персонажей лежат там же в MP3.

## Фактический контекст

Официальное Положение о ТЦК и СП утверждено постановлением Кабинета Министров Украины № 154: [текст постановления](https://zakon.rada.gov.ua/laws/show/154-2022-%D0%BF#Text).
