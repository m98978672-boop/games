# РАЗЛОМ — браузерная первая глава

Открыть `https://m98978672-boop.github.io/games/razlom/` и нажать «Начать вылазку». Это настоящий Web-экспорт Godot 4.4.1, не имитация на HTML и не только страница скачивания. Альтернативный прямой запуск: `web/game.html`.

Нужен современный настольный браузер с WebAssembly/WebGL 2, клавиатурой и мышью. Экспорт однопоточный, поэтому не требует COOP/COEP и SharedArrayBuffer на GitHub Pages. Начальная загрузка включает примерно 42 МиБ WASM до транспортного сжатия. Работать через HTTP(S), не file://. Для локального запуска из корня репозитория: `python -m http.server 8765`, затем `/razlom/`.

Сохранения в IndexedDB этого браузера и этого origin; приватный режим или удаление данных могут их стереть. После запуска нажать «Начать путь». WASD/мышь — движение/обзор, ЛКМ — огонь, E — действие, C — присесть, F — фонарь, Tab — инвентарь, Esc — меню. На ноутбуке можно выбрать низкую графику. Сенсорное управление пока не сделано.

Сборка и тесты: `.github/workflows/razlom-web.yml`, `tools/razlom-web/test.mjs`. Движок/шаблоны берутся из официального релиза Godot. На CI тестируется реальный Chromium с программным WebGL, а не поддельный canvas. Проверяются запуск, меню, движение, сохранение, перезагрузка и загрузка. Артефакты и скриншоты: `docs/razlom/web-evidence/`.

Это законченный цикл первой миссии (выйти, добыть насос, вернуться, получить награду), не вся задуманная кампания. Баланс и полное прохождение человеком остаются непроверенными. Обложка SVG — иллюстрация, не игровой кадр. Реальные кадры есть в отчёте. Геометрия остаётся внутри Godot; никаких сырых мешей в RatCore не передаётся, ToolGuard не обходится. RatCore подключён к странице и экспортированной оболочке. Лицензия Godot и сведения о сторонних компонентах лежат в `licenses/`.
