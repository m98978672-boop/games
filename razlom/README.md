# РАЗЛОМ — страница проекта на Games

Страница распространения исходного Godot-прототипа, не Web-экспорт игры. Архив: `../deliverables/razlom-first-slice-source.zip`. Инструкции и ограничения указаны прямо на странице; полноценной браузерной версии и EXE пока нет. Обложка SVG — декоративная иллюстрация, не игровой скриншот. Меши/текстуры здесь не создаются; это статическая страница с обязательным подключением RatCore.
