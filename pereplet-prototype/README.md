# «Переплёт»: исследовательский прототип

Это отдельный минимальный последовательный эксперимент по концепции из обсуждения;
игра LAST SHORE продолжает использовать существующий движок Three.js. Прототип не
является новым полноценным движком, не содержит графики, физики, многопоточности,
планировщика зависимостей, сети или загрузчика ресурсов и не заменяет игру.

## Что реализовано

`createWorld(entities)` проверяет и упорядочивает объекты. `step(world, rules, dt)`
выдаёт правилам неизменяемый снимок; каждое правило возвращает список изменений.
Шаг проверяет их и атомарно создаёт новое состояние. Одновременная запись одного
поля двумя правилами отклоняется. Входное состояние не изменяется.

Проверка: `node pereplet-prototype/test.mjs` из корня репозитория. Никаких
дополнительных библиотек для эксперимента не требуется.

## Границы и предположения

Идеи снимков состояния, неизменяемых данных и отложенного применения изменений
известны; сочетание здесь — эксперимент, не заявление уникальности. Аналоги и
лицензии не исследованы, юридические выводы не сделаны. Правила — обычные функции
JavaScript: это **не безопасная среда** для чужого кода. Прототип не гарантирует
побитовой детерминизм между платформами и не измеряет производительность.
Параллельность, планировщик, инструменты и графика остаются планом.
