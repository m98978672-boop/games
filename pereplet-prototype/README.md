# «Переплёт»: исследовательское ядро

Это ранний эксперимент, частично подключённый к LAST SHORE. Игра сохраняет
существующие модели, управление и графику на Three.js; **«Переплёт» не является
полной заменой игрового движка**.

## Что подключено к игре

- `clock.mjs` — фиксированный шаг ресурсов в 1/30 секунды, не больше четырёх
  шагов за один игровой кадр. Невыполненное время остаётся в очереди, а не
  отбрасывается. При продолжительной перегрузке симуляция ресурсов может отставать.
- `scheduler.mjs` — проверка зависимостей и стабильная последовательная сборка
  плана правил. Правила одного шага читают один снимок, даже если между ними
  указан порядок. Выполнение сейчас **не параллельное**.
- `core.mjs` — неизменяемый снимок и проверка предложенных изменений до создания
  следующего состояния. Конфликт записи одного поля отклоняется.
- `fire.mjs` — адаптер, через который ядро рассчитывает расход топлива костров.
  Возрождение ресурсов также выполняется по фиксированному шагу; существующая
  игра по-прежнему управляет видами, подсветкой, теплом и сохранением костров.

Между шагами движение эффектов сглажено по накопленному времени. Пауза игры не
выполняет шаги ресурсов. Игровые сохранения используют прежний формат.

## Проверки

Из корня репозитория:

```sh
node pereplet-prototype/test.mjs
node pereplet-prototype/clock-test.mjs
cd last-shore && npm ci && npm run test:build && node tests/pereplet-integration.mjs
```

Проверяются часы с разными интервалами кадров, сохранение задолженного времени,
циклы зависимостей, ошибки, топливо, работа реальных костров, пауза, возрождение
узлов и сохранение. Это не результаты бенчмарков.

## Ограничения

У ядра пока нет собственной графики, физики, многопоточного исполнения,
платформенных адаптеров, редактора, сети и загрузчика ресурсов. Правила — обычные
функции JavaScript, **не безопасная среда** для чужого кода. Побитовая
воспроизводимость между платформами и выигрыш производительности не доказаны.

Идеи неизменяемых снимков, фиксированного шага, графов зависимостей и отложенных
изменений известны; эксперимент не заявляется уникальным. Аналоги и лицензии не
исследованы, юридические выводы не сделаны. Следующий этап — измерить работу на
разных устройствах и расширять ядро по одной механике, не меняя игру без проверки.
