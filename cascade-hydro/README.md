# ⚡ КАСКАД: Живая Вода (`cascade-hydro`)

Браузерный 3D-симулятор строительства гидроэлектростанции, прокладки собственных каналов, реалистичной физики воды и снабжения растущих городов (Three.js + собственное гидродинамическое ядро Well-Balanced SWE).

- ▶️ **Открыть игру:** `cascade-hydro/index.html`
- 🌐 **Сайт со всеми играми на GitHub Pages:** https://m98978672-boop.github.io/games/
- 💻 **Репозиторий всех игр на GitHub:** https://github.com/m98978672-boop/games
- 📋 **Описание физики, экономики и оптимизаций:** [`PLAN.md`](./PLAN.md)

## Сборка и автотесты

```sh
cd cascade-hydro
npm install
npm run build   # собирает минифицированный bundle.js (~680 КБ вместе с Three.js)
npm test        # прогоняет физические тесты воды, плотины, турбин и роста городов
```
