karman/system — образ системы Linux
===================================

Сюда кладётся base.qcow2 — система, которая будет запускаться.

Это ТОЛЬКО ЧТЕНИЕ: лаунчер не изменяет образ. Все изменения сессии
пишутся в karman/state/overlay.qcow2, поэтому:
  * систему можно сбросить, удалив оверлей;
  * контрольная точка — это копия оверлея (мегабайты, а не десятки гигабайт).

После того как образ положен на место, пересчитай манифест:
  python3 tools/prepare_ssd.py <корень накопителя> --rehash

Пока образа нет, лаунчер откажется запускаться и скажет об этом прямо.
