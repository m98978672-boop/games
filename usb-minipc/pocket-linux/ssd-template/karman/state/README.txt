karman/state — состояние сессий
===============================

overlay.qcow2  — все изменения Linux-среды (настройки, установленные пакеты,
                 файлы внутри системы). Создаётся при первом запуске.
                 Удалить оверлей = сбросить систему к base.qcow2.
session.lock   — появляется при старте и снимается при корректном выключении.
                 Если файл остался, лаунчер предупредит об аварийной сессии.
