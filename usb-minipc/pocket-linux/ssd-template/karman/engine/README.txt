karman/engine — портативный движок (QEMU), кладёт пользователь
==============================================================

Здесь должен лежать QEMU, чтобы Linux-среда запускалась без установки
в систему и без прав администратора.

Windows (папка karman/engine/qemu/):
  qemu-system-x86_64.exe
  qemu-img.exe
  и файлы, которые идут рядом с ними в портативной сборке

Linux (karman/engine/qemu/):
  qemu-system-x86_64
  qemu-img

Можно и не класть на накопитель: на Linux лаунчер возьмёт системный
qemu-system-x86_64, если он установлен.

Ничего не устанавливается в Windows автоматически: QEMU запускается
из этой папки как обычная программа.
