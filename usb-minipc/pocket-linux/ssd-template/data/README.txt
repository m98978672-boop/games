data/ — общие файлы
===================

Здесь лежат твои документы. Эта папка видна и без Linux: с Windows, с Linux,
а на Android — через приложение-компаньон (SAF).

public/   — то, что не страшно показать
private/  — то, что нельзя терять (паспорт, ключи, переписка)

ВАЖНО:
* шифрования нет — любой, кто подключит накопитель, прочитает эту папку;
* файлы отсюда НЕ входят в контрольные точки системы;
* не храни здесь единственную копию чего-то важного.
