USB Mini-PC — что лежит на этой флешке
======================================

minipc/config.json          манифест: имя устройства, путь к лаунчеру, sha256
minipc/launch.cmd           меню, которое открывается при подключении флешки
minipc/apps/                сюда кладутся портативные программы
minipc/usage.log            журнал: где и когда флешку подключали

Как это работает
----------------
На компьютере должен быть запущен агент (usb-minipc-agent.ps1 или usbmini.py).
Он замечает новый съёмный диск, находит minipc/config.json, проверяет хэш
лаунчера и только после этого запускает его.

Без агента флешка остаётся обычной флешкой: Windows 10/11 игнорирует
autorun.inf на USB-накопителях, и это правильно — иначе любая чужая флешка
запускала бы на вашем ПК свой код.

Что можно положить в apps/
--------------------------
Портативные сборки, которым не нужна установка: браузер, блокнот, архиватор,
Python embeddable, VLC portable, VS Code Portable и т. п. Ничего из этого
не требует прав администратора.

Важно
-----
Меняешь launch.cmd — пересчитай хэш, иначе агент откажется запускать:
    python3 tools/prepare_stick.py <корень флешки> --force
