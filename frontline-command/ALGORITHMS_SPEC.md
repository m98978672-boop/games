## Контракты и согласованные решения

- Проект — браузерный JavaScript/Canvas; Godot/TileMap не используются. Godot API,
  маски и сцены в нём неприменимы. Адаптация без переписывания игры.
- День = 1440 игровых секунд на ×1; ×2/×4 ускоряют игровое время, пауза не идёт.
  Календаря пока нет. Война заканчивается захватом/разрушением собственного штаба,
  гибелью **отдельного** главнокомандующего или капитуляцией. Текущие авто-победы
  по городам/таймеру ещё не изменены. Гибель игрока-бойца не равна автоматически
  гибели главнокомандующего; его представление и старые сейвы потребуют миграции.
- Обе фракции: поставки по заявке и по расписанию, прибытие 3–5 человек **включая
  водителя** в пределах общего лимита. Если `after_unload=leave`, ПРЕДЛОЖЕНИЕ:
  водитель прибывшей группы становится ботом, его заменяет доступный свой водитель;
  до замены транспорт ждёт, без создания дополнительного бесплатного человека.
- Заказчик разрешил новый отряд, оружие, текстуры и модели. ПРЕДЛОЖЕНИЕ: сохранять
  существующее оружие и его баланс, новые типы/отряд вводить отдельно и симметрично;
  исходные параметры от ближайшего аналога, проверка и отдельный флаг обязательны.
  Существующее `tank_cannon` имеет `aoe`, поэтому не следует молча считать его
  исключительно кинетическим, удаляя фугасное поведение.
- Компромисс по направлениям: четыре существующих PNG остаются в legacy-режиме;
  при новом визуальном флаге добавить четыре диагональных **предрисованных PNG**,
  используя прежний принцип выбора готового направления, не вращение со сглаживанием.
  При подготовке новых ассетов заказчик выбрал процесс: создать оригинальную 2D-
  картинку, разметить контур точками, перенести на модель, обрезать и дорисовать;
  итог — растровый PNG. Сторонние материалы только с проверенными правами.
- Существуют `wall_collision_v2`, `wall_destruction`, `wall_sound_muffle`,
  `pathing_v2` в `data/feature_flags.json`; все включены по конфигу. `alg_save`
  и `alg_deadlock` добавлены со значением false. Экспериментальный подфлаг
  `vehicle_detour_v2` тоже выключен по умолчанию. Остальных требуемых `alg_*`,
  `supply_trucks`, `weekly_arrivals`, `truck_zone_damage`, `firing_points_v2`,
  `world_textures_v2` в реестре пока нет. Общая иерархия мастер-подфлагов и
  побитовый legacy для всех алгоритмов не реализованы и не проверены; предупреждения
  о зависимостях существуют только для нового экспериментального подфлага.
- В том же проекте есть собственные прежние PNG и синтезированные звуки;
  `docs/ASSETS_CREDITS.md` запрещает AI-art без явной лицензии, внешние источники
  требуют лицензии/атрибуции. Допустимость конкретной картинки уточнить **до**
  обводки, её предоставление не означает автоматически разрешение на использование.

### ALG-19: наблюдение сбросов цели

Флаг `alg_deadlock=false` по умолчанию; при включении прежний сброс цели из-за
остановки отправляет событие `pathFailed`, записывает счётчик по фракциям и
ограниченный журнал (размер в `nav_budget.json`), а F3 показывает счётчики.
Это **наблюдение**, не новый алгоритм разрешения пробок: фиксируются только
случаи, дошедшие до существующего сброса цели. Журнал не сохраняется,
причины и отсутствие застрявших не определяются.

`tests/deadlock-observation.mjs`: в сценарии трёх сбросов off даёт 0 новых
событий, on — 3 (2/1 по фракциям), длина журнала при ограничении 2 равна 2,
