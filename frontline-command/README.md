# Frontline: Command
### 2D тактическая песочница: две армии, один Command API

Война двух армий на карте 4096×4096: города, склады, фермы, мосты, фабрики и штабы.
Вы играете за **Альянс** — одним бойцом, отрядом или всей армией сразу, — а
**Легион** воюет против вас тем же кодом, что и ваши войска. Никаких скриптовых
«волн», никаких скрытых бонусов: у обеих сторон одинаковые юниты, мораль, туман
войны, лимиты приказов и задержка радиосвязи.

> Всё, что делает армия, идёт через **один Command API**: приказ имеет цель,
> исполнителей, причину, задержку доставки и явный ответ — принято или отказ
> с причиной. Журнал приказов открыт игроку в HUD.

## ▶️ Запуск

Игре нужен HTTP-сервер (ES-модули не грузятся с `file://`):

```bash
cd frontline-command
python3 -m http.server 8000
# открыть http://localhost:8000
```

Из корня репозитория (как на сайте): `python3 -m http.server 8000` →
`http://localhost:8000/frontline-command/`.

## 🎮 Управление

| Действие | Клавиша |
|---|---|
| Движение (солдат) / камера (командир) | `W A S D` или стрелки |
| Прицел, огонь | мышь, `ЛКМ` |
| Перезарядка / действие | `R` / `E` |
| Переключить уровень управления (солдат ⇄ командир) | `Tab` |
| Выделение отрядов | `ЛКМ` рамкой или кликом; `Shift` — добавить |
| Контекстный приказ | `ПКМ` (идти / атаковать / охранять / достроить) |
| Директива (цель + алгоритм + что после) | `T` |
| Стройка | `B`, затем `ЛКМ` по земле |
| Автопилот по сферам | `P` |
| Создать отряд из выделенных бойцов / на базе | `Ctrl+G` / кнопка «+ Отряд» |
| Пауза / скорость | `Пробел` / `[` `]` или кнопки ×1 ×2 ×4 |
| Отладочный оверлей | `F3` |
| Меню | `Esc` |

## 🧠 Что происходит в мире

* **Три уровня ИИ.** Стратег выбирает, какие точки брать (полезность × расстояние ×
  угроза × слабость); отряд выполняет директиву фазами («натиск», «осторожно»,
  «фланг», «окружение»); каждый солдат живёт своим Behavior Tree — цель, укрытие,
  огонь, мораль, паника, лечение, ремонт.
* **Мораль 0–100.** Без командира падает, в укрытии и на передышке растёт. Ниже 40 —
  отряд может отказаться от приказа; ниже 20 — паника и отход к рубежу.
  Отказ виден в журнале: «мораль 32: отказались выполнять».
* **Восприятие.** Конус зрения ≈110°, слух на выстрелы, память о последней
  позиции врага. За деревьями и бункерами не видно.
* **Снабжение.** Сектора теряют снабжение, склады его восстанавливают, грузовики
  возят боеприпасы (и не едут в бой: почуяли врага — разворот). Ресурсы: боеприпасы,
  материалы, топливо, медикаменты.
* **Сектора и фронт.** Влияние −1…+1 на гекс; удержание N секунд переводит точку,
  смена знака рисует линию фронта; окружённые сектора теряют снабжение.
* **Победа/поражение.** Захват штаба или всех ключевых городов противника.
  Смерть бойца войну не заканчивает — армия воюет дальше, а вы возвращаетесь на базу.

## 🧪 Тесты

```bash
npm test              # логика + симуляция + симметрия + производительность
npm run test:fast     # без 20-минутных прогонов симметрии
npm run test:browser  # дымовой тест в jsdom (нужен npm i --no-save jsdom)
npm run assets        # перегенерировать PNG-спрайты
```

Последние результаты на машине разработки:

| Тест | Результат |
|---|---|
| `tests/logic.mjs` | конфиги, задержки радио, отказы, лимиты — все проверки пройдены |
| `tests/sim.mjs` | 60 с симуляции ≈ 0.2–0.3 с реального времени |
| `tests/perf.mjs` | 392 юнита, тик ≈ 2.8 мс, куча ≈ 20 МБ |

| `tests/browser.mjs` | меню, старт войны, режимы, пауза, ×2, ИИ-против-ИИ — без ошибок страницы |

## ⚠️ Честно о состоянии

* **Графика — процедурный плейсхолдер** (`PLACEHOLDER_REPLACE`, см.
  `docs/ASSETS_CREDITS.md`). Это настоящие PNG-спрайты, но нарисованы скриптом;
  финальный пиксель-арт подключается заменой файлов в `assets/`.
* **Звук синтезируется в WebAudio** по описаниям из `data/audio.json` — файлов
  сэмплов нет, поэтому и лицензионных вопросов нет. Замена на CC0-сэмплы —
  этап 9 плана.
* **Дерево навыков** влияет на бойца игрока и его армию; ИИ получает
  эквивалент по времени войны (`techMods`) — это и есть «симметрия возможностей».
* **Сохранение** пишет состояние войны в `localStorage` (аналог `user://save.json`):
  отряды, юниты, точки, сектора, постройки, склады, время.
* **Известные ограничения:** нет редактора карт, нет мультиплеера (не требуется ТЗ),
  анимации юнитов — 4 направления без покадровой ходьбы, дипломатии нет.
