# Приём файлов модели через Dropbox

В меню игры есть переход к **запросу файлов Dropbox**. Он работает и на статическом GitHub Pages: файлы отправляются на официальной странице Dropbox, не на сервер игры. На данный момент готового запроса и сквозной проверки реальной загрузки нет: владелец создаёт запрос самостоятельно. Подключённый Arena-инструмент Dropbox не предоставляет команду для создания file request.

1. Войдите в Dropbox и откройте https://www.dropbox.com/requests.
2. Создайте запрос файлов, выбрав папку `Frontline-Model-Inbox` в своём Dropbox. Папка уже создана через подключённый инструмент. Не создавайте публичную общую папку: нужен именно **запрос файлов**.
3. Скопируйте ссылку вида `https://www.dropbox.com/request/...`. В опубликованной игре откройте «Хранилище модели ИИ», вставьте ссылку и нажмите «Открыть загрузку в Dropbox». Файлы выбираются и отправляются на сайте Dropbox; дождитесь подтверждения Dropbox.
4. Напишите ассистенту, что загрузка закончена, чтобы он проверил содержимое папки через подключённый Dropbox.

Ссылка запроса — возможность загружать файлы: каждый, кто её знает, сможет занимать место в Dropbox до закрытия запроса. Не публикуйте её. Закройте запрос в настройках Dropbox после использования. Саму ссылку игра не сохраняет и не публикует; при следующем открытии её надо вставить снова. Доступность и лимиты загрузки зависят от Dropbox, его тарифа и свободного места. Не передавайте личные данные и секреты.

Проверка ссылки ограничивает её официальным адресом Dropbox (`https://www.dropbox.com/request/<id>`) и не гарантирует, что запрос активен или принадлежит ожидаемому аккаунту. Не вводите пароли в игру — вход и приём файлов происходят только на Dropbox. Хранилище не подключает модель к WebLLM автоматически. Передача бинарных файлов модели из подключённого Dropbox в рабочую среду Arena и запуск реальной модели пока не проверены: ссылка для скачивания может быть недоступна из песочницы, а крупные файлы ограничены возможностями подключённого инструмента. Не считать загрузку модели или инференс подтверждёнными без проверки.

Существующий временный сервер предпросмотра остаётся отдельным способом и описан в `MODEL_INBOX.md`.
