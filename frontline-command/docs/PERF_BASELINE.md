# PERF_BASELINE — базовая линия и результат 0.10.0

> Правило обновления: сначала снимаем базу, потом меняем код, потом сравниваем те же
> метрики тем же инструментом. База — коммит `5687bce` (v0.9.3), снятая в отдельном
> `git worktree`, чтобы версии не влияли друг на друга.
>
> Команды: `npm test` (включает `tests/perf.mjs`), `node tools/ai-war.mjs --seeds 31-70`,
> `node tools/ai-war.mjs --seeds 31-70 --swap`, `node tests/duel.mjs`, `node tests/symmetry.mjs`.

### Что именно изменило числа

Каждое изменение проверялось с флагом в `data/feature_flags.json` (можно выключить и
получить прежнее поведение). Наблюдения по ходу работы, 20 сидов (31–50):

| Конфигурация | Решено | Средняя, с | Альянс/Легион |
| --- | --- | --- | --- |
| 0.9.3 (база) | 20/20 | 277 | 11 / 9 |
| Зоны по профилю без ограничений | 18/20 | 382 | 10 / 8 |
| + дедупликация зоны (`dedup` 96) | 19/20 | 328 | 13 / 6 |
| + «штурм укреплений» | 19/20 | 398 | 8 / 11 |
| + политика стройки (`buildWanted`) | 36/40 | 317 | 25 / 11 |
| + гистерезис захвата | 36/40 | 290 | 23 / 13 |
| + измор после 900 с | **40/40** | **260** | 26 / 14 |

Без дедупликации ИИ застраивал каждый узел заново после каждого захвата: армии падали до
4–8 бойцов, войны вырождались в перестрелку гарнизонов. Без политики стройки укрепления
съедали материалы, которые нужны производству. Без измора последние 4 войны из 40
зависали на 1200 с при 5–8 бойцах у каждой стороны.

## 3. Откат (rollback)

| Флаг | Что вернёт при `false` |
| --- | --- |
| `build_line` | приказы `build_line` отклоняются |
| `build_zone` | зоны по профилю не планируются (профиль ставит точки, но пусто) |
| `build_templates` | шаблоны застройки отключены |
| `build_priority` | все чертежи равны, `set_build_priority` отказ |
| `build_path_warning` | предупреждение `BLOCKS_PATH` не выдаётся |
| `build_builder_utility` | инженер снова берёт ближайший чертёж |
| `ai_auto_plan` | ИИ не ставит зоны сам |
| `assault_forts` | юниты не стреляют по постройкам |
| `capture_hysteresis` | захват как в 0.9.3 (один порог 1.35) |
| `sudden_death` | война может длиться бесконечно |

## 4. Ограничения замеров

- Замеры сделаны в Node без GPU: это стоимость симуляции, а не отрисовки. FPS в браузере
  проверяется вручную, headless Chromium в песочнице недоступен.
- Войны ИИ×ИИ — стохастика на фиксированных сидах: 40 сидов дают разброс ±3–4 % по доле
  решений, поэтому решения по балансу принимались только на устойчивых сдвигах.
- Игра на людях (руками) в этой версии не проверялась — см. «Известные проблемы» в
  `CHANGELOG.md`.
