# Пошаговый поиск в игровом цикле — эксперимент

`smart_route_v2` подключает к `moveAlongFlow` пошаговый A* после выявления упора. **По умолчанию выключен**. Требует включённых `pathing_v2` и `wall_collision_v2`. Обычное управление игрока, бой и цели внутри зданий не заменяются. Поиск работает не в отдельной копии симуляции, а в игровом цикле; найденные точки проходятся обычным движением. Одновременно есть один активный поиск на мир и до 64 операций поиска за один игровой тик. Это не гарантирует справедливого обслуживания множества юнитов или лимита времени: стоимость операций разная, возможны задержки системы.

При смене цели, состояния бойца или версии/очереди обновления стен поиск или готовый маршрут отбрасывается; по истечении 6 игровых секунд без завершения поиск освобождает слот. Старый признак отказа маршрута у бойца и танка сбрасывается только когда им назначена новая цель: иначе инспектор F8 навсегда переставал наблюдать повторную попытку. Для грузовиков этот статус обрабатывает логистика.

## Повторение

```sh
node tests/smart-route.mjs
node tests/path-retry-observation.mjs
node tools/audit-u-trap.mjs --smart-route
node tools/audit-u-variants.mjs --smart-route
SMART_ROUTE=1 node tests/pathing.mjs
SMART_ROUTE=1 node tests/acceptance/block1-doorways.mjs --attempts=10
SMART_ROUTE=1 node tests/acceptance/block1-deadlocks.mjs --attempts=10
node tools/audit-baseline.mjs 5 --smart-route
```

Исходная U-ловушка: 18/18; расширенная: 216/216 в одиночных искусственных сценах. Это движение через игровую функцию, но не полноценная война или независимая приёмка. Короткий прогон проходов по 10 seed для каждой стороны: восемь одиночных направлений 20/20 каждое; колонна 0/20 по строгим критериям. Встречная пара 0/20 из-за наложений и превышений контрольного шага, хотя все 40 юнитов прибыли; другие виды встречных пробок не проверены. Эти проверки не исправляют колонны.

`PATHING_INTEGRATED_EXPERIMENT.json` содержит парные 60-секундные диагностические серии 3 seed × 100/300/400, состояние флагов, метрики и хеши части исходных файлов. Показатель непрогресса снизился в 6 из 9 серий, в 3 вырос; требуемое снижение на 70% не достигнуто. Сценарии начинаются с одинаковых seed, но бой и общий RNG расходятся, поэтому они не устанавливают причинность. Контрольные значения включают только подходящих юнитов без контакта; это не полная оценка войн. Длительности срезов — Node на машине разработки: p95 в сохранённых сериях 0,302–0,750 мс, максимальный срез 7,135 мс. Это не браузерный FPS и не гарантия бюджета; счётчик операций не равен ограничению миллисекунд.

Пока не пройдены реальная массовая нагрузка, арбитраж встречных колонн/техники, движущиеся препятствия, браузерный бюджет и другие требования блока 1. Поэтому включение флага по умолчанию, автоматический выбор и заявление о приёмке были бы преждевременны.
