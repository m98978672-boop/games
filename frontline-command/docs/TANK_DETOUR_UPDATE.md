# Узкий эксперимент: танк в U-образной ловушке

## Изменение

`tank_detour_v1` использует существующий экспериментальный локальный обход `vehicle_detour_v2`, но только для автономных танков. Он работает вне зданий, вне контакта с врагом, при активных стенах и `pathing_v2`, когда юнит застревает, а направление навигационного поля ведёт от цели. Проверяется доступность кандидатов для радиуса танка, затем выбирается кандидат с минимальной стоимостью по полю. Это не новый глобальный планировщик и не решение столкновений юнитов. Если отдельно включён `vehicle_detour_v2`, его прежнее поведение для всех машин сохраняется.

**Флаг оставлен выключенным по умолчанию.** Выводов об улучшении обычного боя недостаточно. Эксперимент не применяется к управляемому игроком танку, грузовикам или пехоте.

## Проверки

- `tests/tank-u-game-step.mjs`: четыре парных сцены (seed 5 и 11, обе стороны зеркальной геометрии) с реальным `Game.step`. Без флага танки сбрасывали цель через 10,15 с; с флагом все достигли цели за 19,50–20,15 с и обошли препятствие без пересечения стен по проверке полного отрезка движения, без превышения ограниченного шага. Мышление бойцов и прочие системы отключены, врагов нет. Другие U-образные ловушки, группы, игра и бой не подтверждены этим тестом.
- `tests/tank-detour-scope.mjs`: обе фракции и исключения для грузовиков, пехоты, игрока, контакта, зданий, отсутствующего или неподходящего поля и отключённых зависимостей.
- `TANK_DETOUR_WARS.json`: 8 пар обычных игр по 300 игровых секунд, обмен сторон чередуется, отличается только `tank_detour_v1`; диагностика старых сбросов включена с обеих сторон. Зафиксировано **0 применений проверяемого обхода**. В каждой паре собранные показатели совпали: всего сбросы целей танков 1088/1088, грузовиков 416/416, все наблюдённые сбросы 2012/2012, доставки 17/17, убийства 908/908 (off/on). До заданного горизонта войны не завершились. Счётчики всех активных detour в JSON относятся и к старой логике; конкретно новый полевой обход считает `fieldDetours`. Отсутствие применений не доказывает ни пользу, ни безопасность при фактическом срабатывании в реальных боях; доставки в статистике могут быть виртуальными.

Повторить:

```sh
node tests/tank-detour-scope.mjs
node tests/tank-u-game-step.mjs
node tools/tank-detour-wars.mjs --seeds=8 --seconds=300 > docs/TANK_DETOUR_WARS.json
```

Защита дверей и её ограничения описаны отдельно в `DOOR_SAFETY_UPDATE.md`. Физическое исключение прохода юнитов сквозь друг друга по-прежнему не включено по умолчанию. Реальная координация у проходов, отсутствие застреваний и баланс остаются нерешёнными.
