# Движение колонны к цели внутри здания — эксперимент, не приёмка

Флаг `crowd_nav_v2` выключен по умолчанию. Это узкий эксперимент для 6–10 бойцов одной фракции с близкой общей целью внутри здания и выровненной колонной. Нужны `pathing_v2` и `wall_collision_v2`. Бойцы получают разные точки около цели, дальние относительно входа заполняются первыми, движение ограничивается скоростью и не создаёт новых пересечений радиусов. Это не общий планировщик толпы: свободное место, изменившиеся препятствия, разные формации и радиусы, прибывшие или присоединяющиеся бойцы, бой и встречные потоки не доказаны безопасными. Состояния групп не сохраняются как подтверждённый replay. Не включать флаг по умолчанию.

## Повторение

```sh
node tests/crowd-nav.mjs
node tools/diagnose-column-variants.mjs --flag-off
node tools/diagnose-column-variants.mjs
CROWD_NAV=1 node tests/acceptance/block1-doorways.mjs --attempts=100
CROWD_NAV=1 node tests/acceptance/block1-deadlocks.mjs --attempts=10
CROWD_NAV=1 SMART_ROUTE=1 node tests/acceptance/block1-doorways.mjs --attempts=10
node tools/audit-baseline.mjs 5
node tools/audit-baseline.mjs 5 --crowd-nav
```

Стандартный стенд проходов: включено 200/200 колонн, восемь одиночных направлений по 200/200; по наблюдаемым метрикам нет столкновений со стенами, наложений или превышений скорости. Выключенная колонна до эксперимента: 0/200. Дополнительный диагностический стенд: 180/180 входящих колонн (два типа здания, две стороны, три seed, 6/8/10 бойцов, боковые смещения 0–16 пикселей); с выключенным флагом 0/180. Это изолированные сцены без боя, не полноценная проверка всех проходов. Совместно с `smart_route_v2` короткая серия дала 20/20 колонн и одиночных направлений.

Встречная пара по-прежнему **0/20** строго: все 40 бойцов дошли, но зафиксированы 120 кадров наложения и 19 превышений шага. Прочие встречные потоки, техника и доки не покрыты; проверяющий правильно остаётся закрытым.

Парные 60-секундные симуляции seed 5, 7, 11 при 100/300/400 бойцах: метрика непрогресса в одной паре снизилась 82,24 → 80,59, в остальных восьми совпала. Групповой режим реально сработал только в одной паре (6 бойцов, 724 тик-наблюдения); это не доказательство отсутствия регрессий. Среднее время тика изменялось неоднозначно, замеры делались под параллельной нагрузкой и не являются браузерным FPS. Результаты, исходные события и хеши файлов — `CROWD_NAV_EXPERIMENT.json`.

**Блок 1 не принят.** Остаются встречные пробки, массовая производительность, U-ловушки при штатных флагах, логистика и недостающие обязательные испытания. Отдельный стенд не заменяет полный аудит всей игры. Новые ресурсы ещё не добавлены: пользователь просил сначала добиться приёмки.
