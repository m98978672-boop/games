# CHANGELOG — Frontline: Command

## 0.9.1 — баланс ИИ и конец войн
### ИИ (главное)
- **Концентрация сил.** Стратег одновременно ведёт 1–2 наступления (в режиме добивания — 1),
  а не по отряду на каждую из 15–20 «выгодных» целей. Раньше армия распылялась и не
  продавливала ни одну точку.
- **Резерв под наступление.** Оборона больше не съедает все директивы: `defenseCap` —
  ≤60% лимита, и всегда ≥1 отряд остаётся атакующим. Оборона ставится только за свои
  города/склады/штаб, а не на любой сектор с «соседом-врагом».
- **Добивание.** При `врагов ≤ finishUnitsBelow` приоритет отдаётся сектору со штабом
  врага, а требуемая сила падает до `finishPowerFactor`.
- **All-in.** Если 240 с нет захватов (или армия сжалась до ≤2 отрядов при ≤24 юнитах
  у врага) — обороны нет, все отряды идут на одну цель с коэффициентом силы
  `allInPowerFactor`.
- **Гарнизонный баг исправлен:** «часовой» на ключевой точке больше не забирает
  единственный атакующий отряд (ветка отключена в режимах добивания/all-in).
- **Аварийная сборка отряда.** Если у фракции нет ни одного отряда, а на поле ≥3
  свободных бойца — собирается сводный отряд вместо ожидания на базе.
### Мир и баланс
- Новая точка `city_bend` (1646, 2450) — зеркало `city_fork`: раньше у Легиона был
  лишний нейтральный город рядом с базой, что давало перекос ИИ×ИИ.
- `capture.secondsByType`: штаб 16 с, город 12 с, склад/завод 9 с, мост 8 с, ферма 7 с
  (вместо единых 7 с): ключевые объекты нельзя «пробежать» за несколько секунд.
- Порог атаки в первые 180 с повышен множителем `openingThresholdMult`.
### Инструменты и документация
- `tools/ai-war.mjs` + `npm run aiwar` — баланс-прогон ИИ×ИИ по диапазону сидов
  (финалы, тайм-ауты, победители, длительности, флаг `--swap`).
- `docs/BALANCE.md` дополнен новыми рычагами (добивание, all-in, разминка, захват по типам).
- `docs/TEST_PLAN.md`: свежие числа прогона, 7 известных проблем, методика замера баланса.

## 0.9.0 — первая играбельная сборка
### Симуляция
- Мир 4096×4096, 42 гексагональных сектора (odd-q), 18 точек, симметрия поворотом на 180°.
- Юниты: 9 ролей, восприятие (конус 110°, слух, память), мораль 0–100, ранения и медики,
  укрытия, подавление, боеприпасы и перезарядка.
- Отряды: шаблоны, формации, стойки, фазы стратегий, отступление, пополнение.
- Три уровня ИИ: стратег (полезность целей), отряд (FSM), солдат (Behavior Tree, LOD).
- Директивы (цель + алгоритм + после), правила If→Then, автопилот по 6 сферам.
- Экономика: 4 ресурса, производство, склады, грузовики, снабжение секторов, окружение.
- Command API: очередь, задержка радио, ответ, отказ с причиной, отмена, журнал.
- Победа/поражение по штабу и ключевым городам.

### Клиент
- Canvas-рендер: тайлы чанками, спрайты, туман войны, трассеры, взрывы, миникарта,
  оверлей влияния и линии фронта, отладочный оверлей (F3).
- HUD: ресурсы, контроль точек, отряды с полосками, приказы, директивы, стройка,
  автопилот, лента событий, журнал приказов, подсказки, тосты.
- Экраны: главное меню, пауза, настройки, навыки, справка, смерть, итоги войны.
- Управление: солдат/командир, выделение рамкой, контекстный ПКМ, пауза и ×1/×2/×4.
- Сохранение войны и меты в localStorage, автосейв каждые 30 с.
- Звук: синтез WebAudio по `audio.json`, позиционное затухание, пул голосов.

### Ассеты
- 149 PNG, сгенерированы `tools/gen-assets.mjs`: тайлы 32×32, юниты 32×32,
  техника 64×64, постройки 64–128, эффекты, иконки UI, логотип.
- Обложка `cover.svg` для каталога сайта.

### Тесты
- `logic`, `sim`, `symmetry`, `perf`, `browser` (jsdom). Все зелёные.

### Исправлено по ходу
- Мораль больше не «залипает» на нуле: восстановление без контакта, радиус командира 420 px.
- Навигация: `Float64Array` для стоимостей, предрасчёт проходимости, поля потока на отряд.
- Укрытия-постройки перестали запирать юнитов (блокирует только бункер).
- Штаб и точки вне гексагональной сетки больше не «невидимы» стратегу.
- Кривая симметрии карты: рельеф, река, дороги и точки зеркальны относительно центра.
