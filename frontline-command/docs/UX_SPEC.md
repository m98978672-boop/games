# UX_SPEC — интерфейс и взаимодействие

## 1. Принципы
1. Игрок всегда понимает, **почему** что-то не произошло: отказ, задержка и
   причина видны в ленте и журнале.
2. Ни одна автоматика не обязательна: каждую сферу автопилота можно выключить.
3. Один экран — одна задача. Панели закрываются `Esc` до открытия меню.
4. Никаких «секретных» чисел: HUD показывает реальные значения симуляции.

## 2. Экраны
| Экран | Содержимое | Выход |
|---|---|---|
| Главное меню | новая война (солдат/командир), продолжить, демо ИИ-ИИ, навыки, настройки, справка | — |
| Игра | HUD, карта, подсказки | `Esc` → пауза |
| Пауза | продолжить, сохранить, настройки, навыки, справка, меню | `Esc` → игра |
| Настройки | звук, музыка, масштаб, подсказки, дальтонизм, автосейв | «Готово» |
| Навыки | 6 ветвей, цена в XP, доступность | «Назад» |
| Справка | уровни управления, приказы, симметрия | «Понятно» |
| Смерть | итоги бойца, возрождение/командир/меню | выбор |
| Итоги войны | статистика, опыт, новая война | выбор |

## 3. HUD
* **Верх:** фракция, ресурсы (б/п, материалы, топливо, медикаменты), контроль
  точек, убито/потери, скорость ×1/×2/×4 и пауза, время, переключатель уровня.
* **Слева:** список отрядов с полосками HP/БК/морали, состояние, задача.
  Кнопки: «+ Отряд», «Директива», «Авто».
* **Справа:** лента событий (захваты, потери, снабжение) и журнал приказов
  Command API с источником и результатом.
* **Снизу:** выбранный отряд и кнопки приказов (двигаться/атаковать/держать/
  строить/снабдить/стойки).
* **Миникарта** справа снизу: сектора, точки, юниты, рамка камеры, клик — переход.
* **Подсказки** — по центру снизу, из `ui_hints.json`, ненавязчиво.

## 4. Цвета и доступность
* Альянс `#4a7fb5`, Легион `#b5503a` — акценты фракций; фон тёмно-зелёный.
* Цвет не единственный признак: у сторон разные формы значков и подписи.
* Режим для дальтоников повышает насыщенность; масштаб интерфейса 0.8–1.4.
* Все подписи — по-русски, шрифт без засечек, минимальный кегль 11 px.

## 5. Обратная связь
| Событие | Реакция |
|---|---|
| приказ принят | подсказка с задержкой («Атаковать · задержка 1.8 с») |
| приказ отклонён | тост «Отказ: причина» + запись в журнале |
| точка захвачена | тост «Захвачено: …», звук, лента |
| боец ранен/погиб | подсказка / экран смерти |
| нет ресурсов | тост, кнопка постройки приглушена |
| сохранение | тост «Война сохранена», автосейв каждые 30 с |

## 6. Горячие клавиши
Привязки в `data/input_map.json`; в интерфейсе подписи клавиш показываются в
кнопках. `Tab` — уровень, `B` — стройка, `T` — директива, `P` — автопилот,
`F3` — отладка, `Esc` — закрыть/пауза.
