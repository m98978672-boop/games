# Встречная пара у двери — эксперимент, не приёмка

## Что изменено

Под отдельным `door_pair_lanes_v1`, по умолчанию выключенным, добавлен ограниченный манёвр для двух союзных пехотинцев: встречные направления через одну подходящую дверь разделяются по сторонам. При смене цели, смерти/контакте, изменении двери, другом активном маршруте или появлении третьего бойца поблизости манёвр отменяется при следующем обращении к нему. При выключении флага активное состояние очищается при следующем движении бойца. Это не алгоритм колонн, техники, боя, доков или всеобщего отсутствия наложений.

В таблице сохранён исходный более строгий критерий: запрещено **любое** положительное наложение. Отдельная оценка пользовательского допуска `k_overlap=0.7` здесь не выполнена; подмена критерия ею не производилась. Стенды дверей и тупиков возвращают код 1, потому что покрытие категорий неполное, даже когда конкретная сцена пары проходит. Полные результаты: `DOOR_PAIR_DEADLOCK_{OFF,ON}.json`, `DOOR_PAIR_VARIANTS.json`, `DOOR_PAIR_GAME_STEP{,_ISOLATED}.json`, `DOOR_PAIR_DOORWAYS_{OFF,ON}.json`. Проверки совместного включения с обходом препятствий и с crowd-nav дали по 40/40 для узкой сцены пары (`DOOR_PAIR_WITH_VISION.json`, `DOOR_PAIR_WITH_CROWD.json`), но не доказывают совместимость в полной игре.

## Откат и остальные проверки

- При выключенном новом флаге сравнение с предварительным снимком исходников на 20 seed × 61 снимок графа дало 1220 совпадений (`DOOR_PAIR_OFF_COMPARE.json`). Из сравнения удалена новая запись конфигурации; замыкания, глобалы, прототипы, идентичность буферов и некоторые поля времени не полностью охвачены. Это не доказательство побитовой идентичности всей игры.
- 20 пар коротких столкновений по 30 с: 657→657 выстрелов, 863→863 выборочных контакта, убийств 0, войн завершено 0. Сам манёвр ни разу не наблюдался в этих столкновениях, поэтому проверка не оценивает его влияние на бой или баланс (`DOOR_PAIR_COMBAT.json`). 100 полных войн и доверительные интервалы не выполнялись.
- Проверены отмена при смене целей, контакте, гибели/удалении/ранении напарника, управлении игроком, разрушении здания, изменении маршрута, появлении союзника и врага — для двух фракций. Проверка `npm test` завершилась с кодом 0 (`DOOR_PAIR_NPM_TEST.log`); отдельные проверки Chromium off/on и живого тика, основной браузерный smoke и `git diff --check` прошли.

## Вывод

Манёвр перспективен только для изолированной пары. В обычном сценарии рядом быстро появляются другие юниты, и строгая проверка всё ещё не проходит. Эксперимент остаётся выключенным; в действующий opt-in preview его не добавляли. Следующий шаг — исследовать безопасное разруливание более чем двух бойцов с проверкой реального тика, а не отключать защиту или объявлять задачу решённой. Производительность, баланс, полный replay и приёмка блока 0 не подтверждены; публикации изменений нет.
