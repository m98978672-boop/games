# OUTLINES — технические обводы (статус)

> Раздел про обводы из техзадания (§5): коллизии, навигация, окклюдеры, зоны попадания,
> укрытия, точки входа, Y-сортировка — генерируются из «альфы», упрощаются и хранятся в
> `data/outlines/*.json`, с отладочным видом по `F3` и авто-валидацией.

## Честный статус: не сделано в 0.10.0

В этом обновлении обводы **не реализованы**. Ниже — почему, что есть вместо них и что
нужно, чтобы сделать по-настоящему. Обещать «обводы» на словах, не сделав их, хуже, чем
сказать прямо.

## Что есть сейчас (эквиваленты)

| Требование ТЗ | Что в игре | Где |
| --- | --- | --- |
| Проходимость | сетка 4096², тайл 32 px, `isWalkable` | `src/sim/world.js` |
| Навигация | потоковое поле по секторам, `nav.field()/step()/costAt()` | `src/sim/nav.js` |
| Окклюдеры (что мешает огню) | `raycastBlocked()` по тайлам и зданиям | `src/sim/game.js` |
| Укрытия | `world.bestCover()` — оценка по постройкам вокруг | `src/sim/world.js` |
| Зоны попадания | радиус попадания + `coverValue` вместо хитбоксов | `src/sim/units.js` |
| Y-сортировка | отрисовка по `y` в `renderer.js` | `src/render/renderer.js` |
| Отладка | `F3` — оверлей сетки/секторов (без обводов) | `src/main.js` |

## Что мешает сделать по-настоящему

1. **Нет «альфы» в смысле ТЗ.** Спрайты — плоские PNG 64×64 (частично помечены
   `PLACEHOLDER_REPLACE`). Генерировать обводы из альфы технически можно (обход контура по
   маске), но у текущих спрайтов нет ни нескольких уровней детализации, ни отдельных
   элементов (дом = стены + крыша), поэтому обвод получится контуром картинки, а не
   геометрией.
2. **Коллизии сейчас тайловые.** Переход на полигональные обводы означает новый резолвер
   столкновений (юнит — круг, препятствие — полигон) и переписывание `moveUnit`. Это
   отдельный этап с собственным набором тестов; делать его «попутно» с обновлением
   строительства — верный способ сломать и то, и другое.
3. **Нет запечённых данных под обводы.** Формат `data/outlines/*.json` нужно сначала
   спроектировать (схема + валидатор), иначе получится свалка из полигонов.

## План на следующую версию (по этапам)

1. **Схема и валидатор** (`tools/outline-validate.mjs`): полигон здания, точки входа,
   окклюдер, якоря укрытий; проверка самопересечений, минимальной площади, вложенности.
2. **Генератор из альфы** (`tools/gen-outlines.mjs`): обход маски спрайта, упрощение
   Дугласа–Пекера с допуском из данных, запись в `data/outlines/buildings.json`.
3. **Отладочный вид** `F3`: обводы поверх карты, точки входа, окклюдеры, подписи.
4. **Резолвер столкновений** на полигонах + тест «юнит не проходит сквозь стену,
   но проходит в дверь» на 20 сценариях.
5. **Y-сортировка по обводам**: сортировка по нижней точке полигона, а не по `y` центра —
   иначе высокий бункер рисуется поверх бойца, стоящего перед ним.

До выполнения этих пунктов любые упоминания «обводов» в интерфейсе и документации
запрещены — так и сделано: в UI их нет.
