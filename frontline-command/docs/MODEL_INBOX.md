# Хранилище файлов модели в предпросмотре

Кнопка «Хранилище модели ИИ» в главном меню отправляет файлы из браузера в `frontline-command/model-inbox/`, если игра запущена через `tools/model-inbox-server.py`. Это временная приёмная папка, не облачное хранилище и не автоматическая установка модели. Содержимое папки исключено из Git. Большие файлы могут не сохраниться между сеансами из-за ограничений снимков рабочего пространства. Не загружать пароли, токены или другие личные данные; не публиковать ссылку на предпросмотр: пользователь, получивший доступ к нему, сможет загрузить файлы и видеть их имена.

Для локального запуска из `frontline-command`:

```sh
python3 tools/model-inbox-server.py --host 127.0.0.1 --port 8002
```

В Arena-среде предварительного просмотра требуется `--host 0.0.0.0`. Обычный статический сервер и GitHub Pages не предоставляют запись: на них экран покажет, что сервер хранилища недоступен. Этот сервер предназначен только для временного предпросмотра, не для публичного развёртывания; он не заменяет аутентификацию или постоянное хранилище.

Браузер может выбрать несколько файлов по очереди. Разрешены `.zip`, `.bin`, `.json`, `.txt`, `.model`, `.wasm`, `.gguf`, `.safetensors`; максимум 600 МиБ на файл и 1 ГиБ суммарно. Передача идёт порциями до 4 МиБ с прогрессом; имена существующих файлов не перезаписываются. Временный файл становится виден только после полной загрузки и вычисления SHA-256. При закрытии вкладки перед завершением загрузка может прерваться; повторять её нужно с начала. Файл в хранилище не распаковывается и не исполняется.

Защита временного сервера: случайный токен для POST, проверка Origin/Fetch Metadata, ограничение размера и доступного места, запрет обхода путей, атомарное создание без перезаписи, запрет скачивания содержимого приёмной папки и доступа к `.git` через сервер. Эти меры не делают предпросмотр приватным или пригодным для секретных данных. Дополнительные лимиты прокси и сети находятся вне контроля приложения.

Проверка: `node tests/model-inbox.mjs --large` поднимает сервер с отдельной временной папкой. В Chromium через интерфейс отправлены два тестовых файла, включая 10 МиБ с несколькими порциями, и содержимое сверено по SHA-256. Также через прямой локальный API проверена передача искусственного файла 400 МиБ; сетевой прокси Arena и загрузка пользователем файла модели на 400 МиБ в этой проверке не участвовали. Проверены отказ чужому Origin/без токена, попытка выхода из папки, превышение лимита, повтор имени, неверное смещение, неполная загрузка и отмена.
