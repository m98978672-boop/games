## Флаги функций и пороги регрессии

Каждая новая механика включается и выключается в `data/feature_flags.json` без правки кода.

| Флаг | Группа | Вкл. | Что делает |
| --- | --- | --- | --- |
| `build_line` | build | да | Постановка линий (протяжка ЛКМ) и автосоединение секций |
| `build_zone` | build | да | Расстановка зоны по профилю обороны (эшелоны + карта угроз) |
| `build_templates` | build | да | Шаблоны застройки из data/build_templates.json |
| `build_priority` | build | да | Приоритеты чертежей (срочно / обычный / низкий) и очередь стройки |
| `build_path_warning` | build | да | Предупреждение BLOCKS_PATH: чертёж перекрывает проход |
| `build_builder_utility` | ai | да | Выбор строителя по полезности, а не «ближайший» |
| `ai_auto_plan` | ai | да | ИИ-планировщик обороны по карте угроз (та же очередь, что у игрока) |
| `capture_hysteresis` | sim | да | Состояния захвата точки и гистерезис (нет мерцания владельца) |
| `defense_reserve` | ai | да | Резерв и эшелоны обороны (доли отрядов) |
| `assault_forts` | sim | да | Юниты штурмуют вражеские укрепления, а не стоят перед ними |
| `sudden_death` | sim | да | Ничья по очкам после 900 с: война не может длиться вечно |

Пороги регрессии (`data/regression_thresholds.json`): 5 групп —
производительность, баланс, строительство, симметрия. Проверяются тестами и прогонами войн.

## Открытые вопросы баланса

1. **Темп войны (0.10.0).** 80 войн (40 сидов × обе ориентации, лимит 1200 с):
   финалов 80/80, тайм-аутов 0, средняя длительность 260–309 с, коротких (<150 с) 16–18.
   Правило измора (900 с) закрыло последние зависания: 6 из 80 войн решены по очкам.
2. **Перекос сторон.** Суммарно по 80 войнам Альянс 41 / Легион 39 — в пределах шума.
   Дуэль зеркальных армий: 5/3, перекос 63% при пороге 75%.
3. **Стоимость отрядов.** Отряд «Штурм» ≈ 190 материалов — ~3 минуты производства
   в начале войны; при потерях армия восстанавливается медленно.
4. **Летальность.** Винтовка 25 урона при 1.2 выстр./с и укрытии −75% радиуса
   попадания даёт бой на 30–60 секунд — приемлемо, но требует замеров на людях.
5. **Укрепления против штурма.** Пули бьют по постройкам на 90% урона (`tryShootBuilding`),
   бункер 520 HP держится ~30 с под отделением. Нужны замеры на людях: не слишком ли
   долго копать окопы под огнём.
6. **Проверка тюнинга.** `node tools/ai-war.mjs --seeds 31-70 --verbose` —
   таблица финалов, тайм-аутов и длительности; `--swap` меняет стороны местами.

Перегенерация: `node tools/gen-docs.mjs`.
