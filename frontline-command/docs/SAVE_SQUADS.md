# ALG-21: частичное сохранение состояния отрядов

При включённом `alg_save` расширение сохраняет выбранного командира, исходную
численность и счётчики отряда, порог отступления, текущую фазу стратегии,
таймеры и некоторые признаки поведения. Состояние восстанавливается только
после создания отрядов и бойцов. Командир должен быть живым членом того же
отряда и фракции; если ID бойцов повреждены, сохранённый ID командира не
используется. Неверные значения игнорируются. Ссылка на фазу восстанавливается
через конфиг, а не через объект из сериализованного сейва.

`node tests/save-squads.mjs` проверяет обе фракции, старый формат, расширение
без нового поля и некорректные данные. Ранее, например, настройка отступления
`never` после загрузки менялась на стандартную `50`. Тест проверяет возврат
`never`, потерь и командира, а не полную идентичность продолжения всей войны.
При выключенном флаге расширение по-прежнему не записывается.

Это **частичное** улучшение блока 1: не сохранены все поля и ссылки системы ИИ,
отдельные потоки RNG и состояние всех подсистем. Полный replay и приёмочный
сценарий блока 1 по-прежнему отсутствуют; включать флаг по умолчанию на
основании только этого теста нельзя.

## ID расформированных отрядов и очередь приказов

Исправлен отдельный воспроизведённый случай: если расформирован отряд с
наибольшим ID, сохранение не включало его, а счётчик после загрузки начинался
с этого ID. Созданный до доставки старого приказа отряд мог получить чужой
приказ. При `alg_save=true` теперь сохраняется `nextSquadId`; дополнительно
после восстановления ожидающих приказов учитывается максимальный упомянутый
ими ID. Это также защищает указанный сценарий в старом расширении, где
`nextSquadId` отсутствует. Самый старый формат без расширения по-прежнему не
восстанавливает очередь приказов. `tests/save-squad-identity.mjs` проверяет
отказ старого приказа и создание нового отряда, старый и повреждённый счётчик.
Восстановить идентификаторы, которых нет ни в старом файле, ни в его очереди,
невозможно; это не полная детерминированная загрузка.
