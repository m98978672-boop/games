# Ворота для техники: эксперимент, не новая настройка по умолчанию

При исправлении тестовых сцен обнаружено, что `vehicle_exterior_v1` намеренно
заменяет цель ИИ внутри любого здания на внешнюю точку. Это также касается
склада и фабрики с достаточно широкими воротами. Логистика отдельно выбирает
внешние точки погрузки/выгрузки; поэтому сценарий прямой цели за воротами не
является доказательством ошибки логистической доставки. Исправление тестового
индекса убрало ложных «призрачных» препятствующих юнитов: при удалении всех
юнитов нужно очищать и `occupancyGrid`, не только `unitGrid`.

Добавлен **выключенный по умолчанию** `vehicle_gate_access_v1`. В эксперименте
ИИ-техника сохраняет цель внутри здания с подвижными воротами, ширина которых
строго больше диаметра техники плюс толщина стены. Выбор промежуточной точки
также исключает слишком узкие ворота. Остальные случаи сохраняют внешнюю цель;
игрок не затрагивается этим перенаправлением. Проверка ширины консервативна,
не является доказательством проходимости: остаются реальные стены, препятствия,
другие юниты и ограничения маршрута. Погрузка и выгрузка не перенесены внутрь.
Флаг нужно явно включить в `data/feature_flags.json`; существующее поведение
по умолчанию не менялось.

## Результаты и границы

* `VEHICLE_GATE=1 node tests/acceptance/block1-doorways.mjs --attempts=100`:
  `VEHICLE_GATE_DOOR_SCENES.json`, 9 типов × 200 = 1800 независимых сцен,
  1800/1800 прошли, включая въезд/выезд грузовиков и колонну из 10 пехотинцев.
  Без боя, с ручным шагом движения; столкновение со стеной здесь измеряется в
  конечных точках шагов. Это результат **с экспериментом**, не default-on.
* `node tests/vehicle-gate-entry.mjs`: 32 контролируемые сцены через `Game.step`,
  два типа техники, обе стороны, два типа здания, вход/выход, открытые и
  закрытые ворота. Проверены отрезок относительно стен, длина шага, пересечение
  и исходная цель. Боевой ИИ отключён. Отдельно проверены внешний режим и
  исключение пешеходных/узких ворот.
* При выключенном эксперименте `block1-doorways --attempts=10` показал 0/20
  для каждого из двух типов въезда грузовика: грузовик получает внешнюю цель
  и может сразу завершить её, не пересекая ворота. Это ожидаемое следствие
  существующего правила, но не прохождение критерия прямого въезда.
* После очистки индекса `OPPOSING_PAIR_CLEAN_INDEX.json`: 200/200 встречных
  пар пехоты прошли без наблюдаемых наложений, обе стороны, без боя. Общий
  `passed: false` намеренно сохранён: одна пара не покрывает встречные колонны,
  технику и доки. Никаких выводов об отсутствии всех заторов делать нельзя.
* `VEHICLE_GATE_WARS.json`: 8 пар игр ИИ по 180 с, фракции менялись местами,
  порядок on/off чередовался. По событиям сбросов пути: грузовики 41/22,
  танки 196/155, все юниты 738/690, убийства 421/418, доставки 6/8 (off/on).
  При включении было 6645 проверок сохранённой цели; это повторные проверки,
  а **не число проходов**. Игры не закончились, доставка может быть виртуальной,
  RNG расходится после изменения поведения; выборка мала, причинность и баланс
  не установлены. Эксперимент не готов к включению по умолчанию.

Исторический `BLOCK123_AUDIT.json` не обновлялся: результаты отдельных сцен не
заменяют полный аудит. Не установлены приемлемый FPS браузера и поведение длинных
встречных колонн; их нельзя объявлять исправленными.
