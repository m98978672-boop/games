# PLAN — Frontline: Command

Этапы по §17 ТЗ. Каждый этап заканчивается работающей сборкой; следующий
начинается только после приёмки предыдущего. Галочка — сделано и проверено,
`[~]` — сделано частично/плейсхолдер, `[ ]` — впереди.

## Этап 1. Каркас и один боец
- [x] `index.html`, `style.css` (импорт общей темы), `src/main.js`, цикл 60 Гц
- [x] Конфиги: `weapons/units/factions/resources/buildings` + загрузчик
- [x] Мир 4096×4096, тайлы 32 px, рельеф, проходимость, LOS
- [x] Юнит: HP, скорость, зрение-конус 110°, слух, память, оружие, урон
- [x] Command API: очередь, задержка радио, ответ, отказ с причиной, журнал
- [x] EventBus, SpatialHash, детерминированный RNG
- [x] Управление бойцом: WASD, прицел, огонь, перезарядка
- [x] Растровые спрайты 32×32 (PLACEHOLDER_REPLACE) вместо кода-рисования
- **Приёмка:** конус без стен видит на 500 px, слышит выстрел, отступает при HP ≤25%,
  50 юнитов держат 60 FPS, приказы идут через API с задержкой. ✔

- [x] Приказы move/attack/hold/capture/retreat/patrol/escort/supply
- [x] Отказы по боеприпасам, морали, состоянию

  отказы видны в журнале. ✔

## Этап 3. Три уровня ИИ
- [x] Стратег: полезность целей, угрозы, выбор персоналии, лимит директив
- [x] Отряд: FSM по фазам стратегий, якорь, поле потока, отступление
- [x] Солдат: Behavior Tree, укрытия, перезарядка, лечение, ремонт, паника
- [x] Мораль 0–100, порог отказа 40, паника 20, восстановление без контакта
- [x] LOD мышления (near/mid/far), без полных переборов в кадре

  ИИ-против-ИИ даёт убийства и захваты за 20 минут. ✔

## Открытые вопросы
1. Темп войны: 15–25 минут на решение — норма, но бывают тайм-ауты 20 мин
   без победителя (см. `docs/TEST_PLAN.md`).
2. Арт: процедурные спрайты читаемы, но танк и пехотинец в 32 px похожи —
   нужен финальный набор.
3. Звук: синтез даёт «стрельбу», но не даёт «объём» — замена на сэмплы.
