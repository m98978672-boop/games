# 🎨 Единый дизайн всех игр — `shared/`

Эта папка — **единый источник правды для оформления всех игр репозитория**.
Новая игра обязана выглядеть «как все»: тот же тёмный фон, тот же золотой акцент,
тот же HUD-скелет. Поэтому общие стили вынесены сюда, в один файл.

## Как подключить тему к игре

Первая строка `style.css` любой игры:

```css
@import url("../shared/theme.css");
```

Если игру нужно сделать автономной (скопировать одну папку без репозитория) —
скопируйте `theme.css` рядом с `index.html` игры и подключите `./theme.css`.

**Подключены к общей теме:** `road-tycoon`, `euro-haul`, `truck-haul`,
`cascade-hydro`, `last-shore`, `frontline-steel-and-drones` (style.css и inline-стиль play.html),
`game-base`. У каждой игры поверх темы остаются свой оттенок фона и акцент
(`--bg`, `--accent`), а общие токены (`--panel`, `--line`, `--ink`, `--radius`, шрифт,
компоненты HUD) — единые. `folder-os` нарочно не подключается: это пародия на светлую ОС.

- [`theme.css`](./theme.css) — дизайн-токены (`:root`) и общие компоненты HUD.
- Базовая игра-шаблон, демонстрирующая этот дизайн: [`../game-base/`](../game-base/).
- Пошаговая инструкция «как создать новую игру»: [`../game-base/TEMPLATE.md`](../game-base/TEMPLATE.md).

## 1. Палитра и типографика (дизайн-токены)

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#0b0d0c` | фон страницы (почти чёрный, чуть тёплый) |
| `--panel` | `rgba(16,20,19,.92)` | «стеклянные» панели поверх игры |
| `--line` | `rgba(242,236,223,.12)` | тонкие рамки |
| `--ink` | `#f2ecdf` | основной текст (тёплый белый) |
| `--ink-dim` / `--ink-faint` | `#a9a294` / `#6f6a5f` | вторичный и служебный текст |
| `--accent` | `#e8b45a` | **золотой акцент по умолчанию** — переопределяется цветом игры |
| `--accent-2` | `#ffd98a` | светлый акцент: значения, заголовки, свечение |
| `--accent-ink` | `#241a06` | текст на акцентной кнопке |
| `--green` / `--red` / `--blue` / `--violet` | — | статусы: хорошо / плохо / информация / цель |
| `--radius` | `13px` | радиус панелей и кнопок |
| `--font` | `"Segoe UI", system-ui, …` | единый шрифт всех игр |

Шрифт один: `--font`. Подписи к значениям — всегда `UPPERCASE`, мелкие,
с `letter-spacing`; числовые показатели — `font-variant-numeric: tabular-nums`.

## 2. HUD-скелет (одинаковый у всех игр)

```
<canvas> или 3D-сцена — на весь экран под HUD
<header class="topbar">          бренд | статистика | икон-кнопки
<div id="save-indicator">        «● автосохранение»
<aside class="panel side|tools"> боковая панель
<div class="bottom-bar">          чип-подсказка + чип-новость
<div id="pause-flag">            «ПАУЗА · пробел» по центру
<div id="toasts">                уведомления
<div id="modal-root">            модальные окна (помощь, итоги, …)
```

- **`.topbar`**: слева `.brand` (квадрат-логотип с первой буквой на золотом
  градиенте + название + подзаголовок, ссылка на `../index.html`), по центру
  `.top-stats` (`.stat`: подпись + значение), справа `.top-actions` — `.icon-btn`
  (пауза, скорость, звук, сохранить, помощь) и при необходимости `.speed-group`.
- **`.panel`** — стекло: полупрозрачный фон + `backdrop-filter: blur` + рамка
  `--line` + `--radius` + тень.
- **`.bottom-bar`** — `.chip.hint` (подсказка) и `.chip.news` (событие).
- **`.toasts`** — уведомления с цветной левой границей (`.good` / `.bad` / `.win`).
- **`.modal-root.open`** → `.modal-backdrop` (блюр) → `.modal`.
- **Кнопки**: `.btn` и `.btn-primary` (золотой градиент).

## 3. Обязательные правила для каждой игры

1. **Структура папки**: `index.html`, `style.css`, `src/*.js` (обычные
   `<script src>`, без модулей и сборки), `README.md`, `PLAN.md`, `cover.svg`
   (1440×810), при желании `tests/`, `tools/`.
2. **Шапка HTML**: `lang="ru"`, `viewport`, `title` + `description`,
   `<meta name="theme-color">`, favicon — inline SVG data URI, обложка `cover.svg`.
3. **Без внешних зависимостей**: никакого CDN, ничего не качается извне;
   игра открывается двойным кликом по `index.html` и работает на GitHub Pages.
4. **Сохранение** — `localStorage` (автосохранение + индикатор `#save-indicator`).
5. **Клавиатура**: `Space` — пауза, `H` — помощь, `S` — сохранить, `M` — звук,
   `Esc` — закрыть окно.
6. **Доступность и адаптив**: работает мышью и пальцем, есть `@media`-ветки
   для узких экранов и `prefers-reduced-motion`.
7. **Витрина**: карточка игры добавляется в корневой `index.html`,
   `site/index.html` и в корневой `README.md` (обложка `cover.svg`, бейдж версии,
   кнопки «Играть» / «Об игре»).
