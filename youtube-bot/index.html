После разрешения Google сервер сохранит токен в зашифрованном хранилище и попробует загрузить короткий тестовый ролик как приватный. Тестовое видео не публикуется для зрителей.

Продолжить через Google

Пароль Google не передаётся этому сайту. Запрашиваемое разрешение — загрузка видео на YouTube. Не нажимайте повторно, если загрузка завершилась с неопределённым результатом: сначала проверьте YouTube Studio.

Комментарии с телефона

Подключите Google отдельно с правом только на чтение, укажите своё видео и посмотрите до 50 последних комментариев. Ответы не публикуются. Доступ хранится только в памяти этой вкладки.

Google может попросить подтвердить доступ только на чтение.

Это просмотр в браузере, не автоматическая обработка ИИ. Комментарии и токен не сохраняются на сервере. Для отзыва разрешения откройте подключения Google.

Что делает эта версия

  1. Открывает официальную страницу согласия Google.
  2. Возвращает OAuth-ответ на защищённый сервер Supabase.
  3. Шифрует и сохраняет токен на сервере; затем выполняет один приватный тест загрузки.

Это пока проверка авторизации и разовой приватной загрузки. Постоянное расписание, автоматическая генерация роликов и регулярные публикации ещё не включены.

Тест может не загрузиться, если OAuth redirect URI ещё не настроен в Google Cloud Console, YouTube API не включён или аккаунт/канал не имеет доступа. При отмене согласия видео не загружается.
