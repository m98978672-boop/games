Подключение комментариев

Эта страница помогает скопировать нужное значение из файла Google. Файл читается только на вашем телефоне и не отправляется сайту.

1. Выберите новый скачанный JSON-файл Google.

2. Нажмите кнопку:

Файл ещё не выбран.

3. Откройте Supabase, найдите YOUTUBE_COMMENTS_CLIENT_SECRET, вставьте скопированное значение и нажмите Save.

Открыть Supabase

Не отправляйте секрет в чат и не делитесь им. После сохранения напишите в чат «готово».
