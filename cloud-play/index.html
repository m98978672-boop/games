01ОФИЦИАЛЬНЫЙ STEAM CLIENT⇩

Установка и передача в LAN

PLAYBRIDGE не копирует игровые депо. Кнопка установки открывает Steam для выбранного AppID; сам Steam решает, брать файлы с локального устройства или с официального CDN.

  1. На обоих устройствах открой Steam → Настройки → Загрузки.
  2. Разреши «Передачу файлов игр по локальной сети».
  3. На новом устройстве запусти установку игры из этой библиотеки.

БЕЗОПАСНОСТЬ И ПРАВА

Пароль Steam не проходит через PLAYBRIDGE

OpenID подтверждает SteamID; Web API показывает только доступные сведения. Для удалённого запуска нужно соблюдать условия Steam и лицензии на игры; дополнительные договорённости могут потребоваться для публичного сервиса. Сторонние копии Steam-файлов не храним.

БОЛЬШОЙ ЭКРАН

ПК и ноутбук

Windows portable-пакет запускает backend на этом компьютере. В разделе «Пульт» можно включить доступ с телефона по коду: backend остаётся локальным, но на время сессии открывает отдельный порт в домашней сети.

▯
СЕНСОРНЫЙ ЭКРАН

Телефон и планшет

Подключись по коду с компьютера и управляй им из раздела «Пульт»: экран, стрелки, ввод, Esc и запуск Steam Big Picture. GitHub Pages остаётся статическим интерфейсом — для управления нужен запущенный ПК.

Как телефон подключается к компьютеру?

На компьютере открой раздел «Пульт» и включи доступ — появится шестизначный код и адрес вида http://192.168.…:4175/cloud-play/. Открой этот адрес на телефоне в той же Wi-Fi сети, введи код и подтверди запрос на компьютере. Код одноразовый и действует две минуты.

Безопасно ли оставлять такой доступ включённым?

Доступ выключен по умолчанию и открывается только по твоему нажатию. Пока он включён, слушается отдельный порт в локальной сети, а подключиться можно лишь после подтверждения на экране компьютера. Кнопка «Выключить доступ» закрывает порт и завершает все сессии; сессия также истекает через 30 минут.

Синхронизируются ли ключ Steam API и настройки?

Нет. Не копируй ключ или файл настроек на телефон. В portable-версии ключ хранится на ПК и используется только локальным backend; для нескольких устройств нужен общий HTTPS backend. Список игр запрашивается у Steam, а Dropbox хранит только отдельный снимок метаданных, если он настроен.

Можно ли запускать или стримить игры с телефона?

PLAYBRIDGE показывает экран компьютера отдельными кадрами примерно раз в секунду и отправляет разрешённые клавиши — этого хватает для меню, библиотеки и Steam Big Picture, но не для плавной игры. Для полноценного видеопотока используй Steam Remote Play или Steam Link; из раздела «Пульт» открывается их официальная страница.

Как добавить PLAYBRIDGE на главный экран телефона?

На Android открой сайт в Chrome и выбери «Установить приложение» или «Добавить на главный экран». На iPhone/iPad открой сайт в Safari, нажми «Поделиться» → «На экран “Домой”». Для установки PWA нужен HTTPS (или localhost при локальном тесте); авторизация всё равно требует доступного backend.

ЛОКАЛЬНАЯ НАСТРОЙКА

Подключить библиотеку Steam

Ключ нужен только для чтения списка игр. Он хранится на этом компьютере в папке профиля пользователя и не отправляется на GitHub или в Steam OpenID.

Получить ключ можно на официальной странице Steam. Не вставляй его в чат. Пустое поле оставит сохранённый ключ без изменений.
