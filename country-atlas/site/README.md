# Белый холст — проверка формул

Первый шаг реализации по промту (§0.5, R-34.36a). Здесь нет моделей, текстур, цветов и сети —
только белое полотно, сетка, три коробки и счёт по формулам §35–§36.

## Как открыть

Два способа, оба офлайн:

1. Двойной клик по `index.html` (работает через `file://`, сборка не нужна).
2. Локальный сервер, если удобнее смотреть с телефона в той же сети:

```
cd country-atlas/site
python3 -m http.server 8017 --bind 0.0.0.0
# открыть http://localhost:8017/
```

## Что можно проверить руками

| Вкладка | Что показывает |
|---|---|
| **Столб** | запись `(X;Y)Hp(X,Y;X,Y)` под курсором; при наведении на дом — его столб: `p`, пары, `D`, `h`, `θ`, `τ`, верх |
| **Грань** | ID кубика по F-72 (64 бита), расшифровка F-73, состояние текстуры (целая / трещина / облом), шаг износа F-74 |
| **QООВЗ** | `Q` = центр + радиус + прямоугольник камеры (F-81), `k_px` (F-83), число слоёв (F-84), видимость объектов `A = 1` (F-82) |
| **Формулы** | самопроверка: 18 формул × 20 значений, 360 проверок, каждая строка ✓ или ✗ |
| **Журнал** | что нажимали и что посчиталось |

Управление: колесо — масштаб, перетаскивание — панорама, клик — закрепить точку, `Esc` — снять.

## Что нарочно сделано «белым»

- Никаких материалов и света: здания — белые прямоугольники с чёрным контуром и линиями этажей.
- Рельеф показан только изолиниями каждые 5 м (без заливки).
- Нет ни одной текстуры: номер текстуры `t` — это число в ID, а не картинка.

Краски будем наносить постепенно, как договорились.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и стили, без зависимостей |
| `core.js` | формулы F-71…F-89 и проверки; грузится и в браузере, и в node |
| `app.js` | холст, панели, события |
| `selftest.js` | `node site/selftest.js` — те же 360 проверок без браузера |

## Проверка из консоли

```
cd country-atlas/site
node selftest.js
```

Ожидаемый вывод: `формул: 18, проверок: 360/360, провалов: 0`, затем три строки про дома
`B1`, `B2` и ID грани.

## Что здесь пока не реализовано (осознанно)

- Из 89 формул промта — только 19 (F-71…F-89): остальные относятся к ИИ и экономике.
- Из 32 алгоритмов — ни одного: A28 (строительство горы) появится, когда будем добавлять рельеф.
- Нет текстур, света, звука, сохранений, мобильных жестов и LOD.

Это харнесс для проверки счёта, а не игра.
