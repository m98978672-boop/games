# РАТГРАД

Игра-карта: страна, собранная из точек, где каждый дом, дорога и человек считаются по формулам
из промта. Сейчас это два рабочих экрана:

| Страница | Что это |
|---|---|
| [`index.html`](index.html) | **краски**: 3D-рельеф 600 × 600 м по A28, вода, изолинии, дома, свет и тени |
| [`site/index.html`](site/index.html) | **белый холст**: разбор записей, ID граней, QООВЗ и 360 проверок формул |

Оба работают офлайн, без сети и CDN. Открываются двойным кликом (`file://`) или с сервера.

## Краски: что уже видно

- **Рельеф** — 36 чанков по 100 м, шаг 2 м (65 × 65 точек), высоты от −6 до +116 м.
- **12 шагов A28**: FBM → гребни (F-79) → domain warp → маска плит → эрозия (8 итераций) →
  сток → шкала −8…117 → террасы по 1 м → цвета → нормали → LOD-чанки → упаковка.
- **Цвет** по высоте и уклону: вода, песок, луг, лес, камень, снег (палитра §2.2).
- **Изолинии** каждые 5 м — как на белом холсте, но поверх красок.
- **Дома**: шесть коробок с цветными стенами, скатными крышами и тёплыми окнами.
- **QООВЗ** — чёрное кольцо радиуса 250 м вокруг центра.

Управление: тянуть — поворот, Shift + тянуть — сдвиг, колесо — зум.

## Проверки

```
npm test                      # рельеф + 360 проверок формул
node tests/heightfield.mjs    # детерминизм, диапазон, вода, эрозия, гребень
node site/selftest.js         # 18 формул × 20 значений = 360/360
node site/smoke.js            # прогон панелей на заглушке DOM
```

## Сборка

```
npm install
npm run build     # src/ → game.js (игра) и terrain-worker.js (воркер рельефа)
```

`game.js` и `terrain-worker.js` лежат в репозитории — страница работает без сборки.

## Устройство

| Файл | Что внутри |
|---|---|
| `src/heightfield.js` | A28: шум, гребни, warp, плиты, эрозия, террасы; чистый модуль без DOM |
| `src/terrain.js` | чанки, воркер-пул, геометрия, цвета, изолинии, вода, высота в точке |
| `src/palette.js` | палитра и правило «цвет по высоте и уклону» |
| `src/buildings.js` | дома: стены, крыши, этажи, окна |
| `src/main.js` | сцена, небо, свет, камера, HUD, переключатели |
| `src/terrain-worker.js` | воркер: считает чанк и отдаёт буфер переносом |
| `game.js`, `terrain-worker.js` | собранные бандлы (esbuild, IIFE) |
| `site/` | белый холст и его проверки |

## Многоядерность

Чанки считаются пулом воркеров (`hardwareConcurrency − 1`, до 4) и передаются в главный поток
переносом `Float32Array` — без копирования. Если воркеры недоступны (`file://` или запрет),
рельеф считается локально тем же кодом: результат идентичен, детерминизм проверяется тестом.
