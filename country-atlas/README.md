# РАТГРАД

Игра-карта: страна, где каждый дом, дорога и человек считаются по формулам из промта.
Сейчас страна смотрится **сверху, в 2D**, и занимает ровно **700 × 700 км**.

| Страница | Что это |
|---|---|
| [`index.html`](index.html) | **игра**: карта 700 × 700 км сверху — море, горы, сетка, 18 поселений, простой сдвиг и зум |
| [`site/index.html`](site/index.html) | **белый холст**: разбор записей, ID граней, QООВЗ и 360 проверок формул |
| [`3d.html`](3d.html) | **3D-опыт** (история): рельеф по A28, вода, изолинии, дома — заморожен, не расширяется |

Все три работают офлайн, без сети и CDN: двойным кликом (`file://`) или с сервера.

## Карта: что уже видно

- **Мир** — ровно 700 × 700 км, `−350…+350` по обеим осям, сид 424242; высоты −180…1995 м,
  море 23.7 %, выше 1500 м — 4.3 %, снег с 1750 м. Четверти читаются: море на юго-западе,
  горы на северо-востоке, тайга на севере, степь на юго-востоке.
- **Слои**: обзор мира 1024 × 1024 px считается один раз (≈0.8 с в воркере); при зуме ≥ 3.5 px/км видимая область
  пересчитывается в воркере (`map-worker.min.js`) и приходит буфером.
- **Сетка** в километрах: шаг 50 / 25 / 10 км по масштабу; подписи по осям; масштабная линейка.
- **18 поселений** на суше 12…620 м, не ближе 45 км друг к другу, с подписями и высотой.
- **Дороги** (§40): 7 хабов (столица Дорн + 6), каркас магистралей, региональные, местные и
  грунтовые; A* по сетке 4 км обходит горы и воду. Сейчас: 32 ребра, 11 469 км, мостов 2,
  ни одного тупика. Слой включается галочкой «дороги §8».
- **HUD**: курсор, высота под курсором, масштаб, центр, FPS.
- **QООВЗ** — пунктирное кольцо 250 м вокруг центра (слой можно отключить).

Управление простое: тянуть мышью или пальцем — сдвиг, колесо или щипок — зум к курсору,
стрелки — сдвиг, `+ / − / ⌂` — зум и возврат в центр. Инерции, поворотов и наклона нет.

## Проверки

```
npm test                      # рельеф 3D + 360 проверок формул
node tests/world2d.mjs        # мир 2D: 8 групп, формулы F-90…F-99 по 20 значений
node tests/roads2d.mjs        # дороги: 8 групп, F-100…F-107 по 20 значений
node tests/heightfield.mjs    # 3D-рельеф: детерминизм, диапазон, вода, эрозия, гребень
node site/selftest.js         # 18 формул × 20 значений = 360/360
node site/smoke.js            # прогон панелей на заглушке DOM
```

(сейчас: критично 0, важно 0).

## Сборка

```
npm install
npm run build
```

`build.mjs` собирает четыре файла (esbuild, IIFE, minify):

| Вход | Выход | Зачем |
|---|---|---|
| `src/main2d.js` | `bundle.js` | 2D-карта (основная игра) |
| `src/main.js` | `bundle-3d.min.js` | 3D-опыт на `3d.html` |
| `src/map-worker.js` | `map-worker.min.js` | обзор и патчи карты |
| `src/terrain-worker.js` | `terrain-worker.min.js` | чанк 3D-рельефа |

Бандлы лежат в репозитории — страницы работают без сборки.

## Многоядерность

Карта считается в воркере одним прямоугольником видимой области: пиксели приходят
`Uint8ClampedArray` переносом, без копирования. На `file://` воркер недоступен — тот же код
считает обзор в главном потоке, результат идентичен (детерминизм проверяется тестом).
