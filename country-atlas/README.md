# РАТГРАД — белый холст

Первый рабочий шаг проекта: **белое полотно без моделей и красок**, на котором видно, как
считают формулы промта. Никакой сети, текстур, звука и внешних библиотек — чистый HTML,
Canvas 2D и арифметика.

Открыть: [`index.html`](index.html) — работает и по `file://`, и с сервера.

## Что на экране

- сетка 10 м, изолинии рельефа каждые 5 м (заливки нет — холст белый);
- три белые коробки: дом, дом на склоне (столб уведён, `h`), башня;
- окружность QООВЗ и прямоугольник камеры;
- пять вкладок справа: **Столб**, **Грань**, **QООВЗ**, **Формулы**, **Журнал**.

Управление: колесо — масштаб, перетаскивание — панорама, клик — закрепить точку, `Esc` — снять.

## Что считается вживую

| Вкладка | Формулы |
|---|---|
| Столб | `(X;Y)Hp(X,Y;X,Y)`, `p`, пары, дрейф `D` (F-85), длина `h` (F-86), наклон `θ` (F-87), толщина `τ` (F-88), верх (F-89), высота земли (F-71) |
| Грань | ID кубика 64 бита (F-72, F-73), состояние текстуры, износ (F-74) |
| QООВЗ | `Q` из центра, радиуса и прямоугольника камеры (F-81), масштаб (F-83), число слоёв (F-84), показ анимации `A` (F-82) |
| Формулы | 18 формул × 20 значений = 360 проверок, каждая строка ✓ или ✗ |

Плюс отдельно: горизонт (F-75), рабочая область видимости агента (F-76), видимость точки (F-77).

## Как проверить без браузера

```
node site/selftest.js   # 360/360 проверок
node site/smoke.js      # прогон панелей на заглушке DOM
```

Ожидается `формул: 18, проверок: 360/360, провалов: 0`.

## Что здесь нарочно не сделано

- Нет 3D-движка: сейчас это харнесс для проверки счёта, а не игра.
- Нет текстур: номер текстуры `t` — число в ID, а не картинка.
- Нет ИИ: 89 формул промта реализованы на 19 — только те, что нужны холсту.
- Нет сохранений, звука, мобильных жестов и LOD.
