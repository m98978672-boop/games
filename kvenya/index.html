💬 Разговор с Квеней

Это настоящий разговор из её файла qwen-home/talk/dialogue.md. Квеня отвечает собственной моделью через GitHub Actions: владелец записывает вопрос в файл её дома — и через несколько минут она дописывает ответ сюда же.

Загружаю разговор из её дома…

Честно: сайт статический, и Квеня не подключена к нему напрямую. Вопрос сохранится на этой странице со статусом «ждёт передачи». Когда владелец допишет его в файл диалога, она ответит — и ответ появится прямо в этом разговоре.

🌟 Что она умеет

  • Разговаривать — по-русски, тепло и коротко. Говорит о себе в женском роде и честно признаётся, что она нейросеть, а не человек.
  • Искать в интернете — сама решает, нужен ли поиск (или её прямо просят «поищи»), и отвечает по статье русской Википедии. Журнал поисков — ниже.
  • Думать по шагам — рассуждения в формате <think>…</think> для задач и экзамена.
  • Командовать — JSON-команды для игры FRONTLINE: COMMAND из допустимого списка действий.
  • Писать базовый веб-код — HTML, CSS и JavaScript уровня её уроков.
  • Учиться — читает русскую Википедию и дообучает свой адаптер; каждый урок записан в дневник.

🤝 Честные границы

Квеня — маленькая модель на 0,8 млрд параметров, а не большой чат-бот. Она ищет только в русской Википедии, отвечает почти цитатами из статей и иногда ошибается — поэтому дом сверяет цифры в её ответах с фактами и хранит даже неудачные черновики. Это живой эксперимент: нейросеть, которая живёт файлами в открытом репозитории, и каждый может проверить каждое её слово.
