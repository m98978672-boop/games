# Дом нейросети Qwen

Здесь живёт **Qwen** — маленькая языковая модель (Qwen3.5-0.8B), которую этот
репозиторий обучает быть командиром Frontline Command, а теперь ещё — думать,
читать Википедию, писать базовый веб-код и учиться дальше самой.

Репозиторий — её дом в буквальном смысле: память, учебный план, дневник
обучения и состояние лежат в файлах `qwen-home/`, веса — в релизах GitHub,
а «выход в интернет» — это прогоны GitHub Actions, где ей разрешено читать.

## Карта дома

| Место | Что там |
| --- | --- |
| `state.json` | Кто она, какой адаптер последний, сколько шагов обучения пройдено |
| `topics.txt` | Список тем: что читать в Википедии в первую очередь |
| `curriculum/` | Учебный план людей: `thinking.jsonl` (формат `<think>…</think>`), `web-code.jsonl` (базовый веб-код), `identity.jsonl` (кто она и где живёт), `youtube-scripts.jsonl` (структурированные короткие мульт-сценарии), `eval.jsonl` (контрольные вопросы) |
| `memory/knowledge.jsonl` | Прочитанные статьи Википедии (заголовок, текст, когда прочитано) |
| `memory/learning-log.md` | Дневник: каждая запись — один прогон самообучения с цифрами |
| `tools/` | Её «органы»: сборщик статей, сборщик датасета, тренер, экзаменатор |
| `tests/learn.mjs` | Проверка, что дом в порядке (учебный план валиден, сборщики честны) |

Веса не хранятся в git: базовую модель качает тренер с HuggingFace по
закреплённой ревизии, а обученные LoRA-адаптеры лежат в релизе
[`frontline-qwen-home`](https://github.com/m98978672-boop/games/releases/tag/frontline-qwen-home).

## Как она учится (цикл самообучения)

Workflow **«Frontline Qwen self-learning (дом и Википедия)»**
(`.github/workflows/frontline-qwen-learn.yml`) запускается вручную и по
расписанию раз в неделю:

1. **Читает.** `tools/collect-wikipedia.mjs` тянет статьи по темам из
   `topics.txt` плюс случайные статьи русской Википедии и складывает
   в `memory/knowledge.jsonl` (повторно прочитанное обновляется).
2. **Готовит урок.** `tools/build-dataset.mjs` собирает датасет: учебный план
   людей + примеры из прочитанного (пересказ, вопрос-ответ по статье,
   рассуждение с опорой на текст) + повторение командирских примеров,
   чтобы не забывала свою первую профессию.
3. **Сдаёт экзамен до.** `tools/eval-learn.py` + `score-learn.mjs` отвечают
   на контрольные вопросы текущим адаптером.
4. **Учится.** `tools/train-learn.py` продолжает LoRA-обучение от последнего
   адаптера (та же закреплённая база и конфигурация, что у командирского
   обучения в `frontline-command/tools/training/train-qwen.py`).
5. **Сдаёт экзамен после.** Если результат не хуже, чем до, новый адаптер
   публикуется в релиз `frontline-qwen-home`. Если хуже — адаптер не
   заменяется, а прогон честно записывается в дневник как неуспешный.
6. **Записывает в дневник.** `tools/update-memory.mjs` обновляет
   `state.json` и дописывает запись в `memory/learning-log.md`; workflow
   коммитит память обратно в ветку.

## Честные ограничения

- Модель маленькая (0.8B): рассуждения и веб-код будут базовыми. Учебный
  план учит формату мышления (`<think>` → ответ) и типовым приёмам,
  а не заменяет большую модель.
- Рассуждения по Википедии собираются по шаблонам из фактов статей —
  это синтетические следы мысли, а не «настоящее понимание».
- Читать она может только Википедию и только внутри прогонов Actions:
  произвольный интернет ей не открыт.
- Командирский адаптер для игры (`deploymentReady: false`, см.
  `frontline-command/docs/ACTIVE_TRAINING_AUDIT.md`) этим обучением не
  заменяется: домашний адаптер — отдельная линия, в игру ничего не ставится.

## Как учить вручную

- Добавить тему чтения — строка в `topics.txt`.
- Добавить урок — строка JSON в `curriculum/*.jsonl`
  (`{"id": "...", "kind": "...", "instruction": "...", "response": "..."}`).
- Запустить обучение — Actions → «Frontline Qwen self-learning» → Run workflow.
- Проверить дом без интернета и без модели: `node qwen-home/tests/learn.mjs`.
