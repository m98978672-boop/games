# Проверки без браузера

Игра проверяется двумя скриптами — это дешевле, чем каждый раз открывать вкладку.

```bash
# 1. Генерация мира, рельеф, ходьба, столкновения, небо, подбор, камера
node tests/smoke.mjs

# 2. Вся игра в jsdom с заглушкой WebGL-рендерера:
#    старт, подбор (E), еда (1/2), сумка (I), пауза, автосейв, погода, смерть
npx esbuild src/main.js --bundle --format=iife --target=es2020 \
  --outfile=tests/.harness-bundle.js \
  --alias:three=./tests/three-stub.js \
  --alias:three/addons/utils/BufferGeometryUtils.js=./node_modules/three/examples/jsm/utils/BufferGeometryUtils.js
node tests/harness.mjs
```

`three-stub.js` — это настоящий Three.js, у которого `WebGLRenderer` заменён заглушкой,
чтобы логика игры работала в Node без видеокарты.

## 2.1. Живность и бой

`node tests/mobs.mjs` — звери в мире, урон по кабану, лук и стрелы, бинт, запрет готовки без костра,
переключение слотов колесом, укус кабана.

## 2.2. Шахта и кузница

`node tests/mine-forge.mjs` — два слоя под землёй, вход через арку, пробивание стены
жилы киркой и добыча, лава в глубинном слое, ковка процедурного предмета с моделью,
заточка кованого (крафтовый нож не точится), установка верстака и точила, панели.

## 2.3. Песочница механик

`node tests/sandbox.mjs` — животные смотрят по ходу движения, хитбоксы по габаритам модели,
зазор 5 см между статикой, копание слоя земли с осыпанием песка и затоплением,
креатив (F2 → F: ∞ предметы, полёт, неуязвимость), ранения по частям тела и бинт,
копание вглубь шахты и выход на поверхность.

## 2.4. Версия 0.13: слои, полёт, F9, бот

`node tests/v013.mjs` — песок/дёрн → камень → пустота шахты, вода только на пляже,
лунка со стенками и дном, полёт (Space/Shift/зависание), F9, все 17 проверок бота.
`node tests/v013-browser.mjs` — то же в настоящем браузере: бот по F8 ходит и ведёт отчёт,
F9 отпускает курсор, копание доходит до пустоты, полёт работает. Нужен сервер на :8080.

## 2.5. Версия 0.13.1: яма в блоках, трава из оттенков, F9

`node tests/v013.mjs` — яма проседает блоком ровно по сетке, стенки и дно по слоям
«земля → камень», вокруг земля цела; трава из разных оттенков (разброс яркости и насыщенности);
вода только на пляже; полёт; F9; 19 проверок бота.
`node tests/v013-browser.mjs` — то же в браузере (бот F8, F9, копание, полёт).

## 2.6. Версия 0.14: яма вырезана в рельефе

`node tests/v013.mjs` — яма от лопаты **вырезана** из сетки: треугольники земли на клетках
удаляются из индекса рельефа, край идёт по узлам сетки, высоты узлов не меняются (ничего
не «насаливается» поверху), внутри дно и стенки по слоям «земля → камень», ступени

на пляже; полёт; F9; 19 проверок бота (в том числе «яма — дыра в рельефе, край по сетке»).
`node tests/shot-pit.mjs` — скриншоты выкопанной ямы (`tests/shot-pit*.png`), нужен сервер :8080.

## 2.7. Версия 0.15: обвал между ямами и прочность пород

`node tests/v013.mjs` — рядом с выкопанной ямой копаешь вторую: стенка рушится, ямы
сливаются в одну дыру без перегородки (ям на карте 1, между ними пол ямы, а не дёрн);

## 2.8. Версия 0.16: обводки, почва, новые деревья, звери и рыбы

`node tests/v016.mjs` — обводки всех моделей (2328 оболочек, 108k треугольников):
герой упирается в оболочку и не проходит сквозь ствол, спиленное дерево обводку
теряет; **F3 → Ж** включает и выключает зелёный каркас обводок; почва и трава

ходьбы и плавания.

## 2.10. Версия 0.18: ровная земля, ступени, обводки по стволу, лодка

`node tests/v018.mjs` — девять групп:

1. **сосна цельная** — в хвое нет пустых полос по высоте (просвет 0.00 м);
2. **проходы между стволами** — середина между деревьями свободна (100 %);
3. **валуны** — низкий (0.43 м) переступается, высокий — нет;
4. **плоская земля под моделями** — перепад по пятну под стволом ≤ 5 см;
5. **дома зверей** — поляна без моделей, звери держатся у дома; **звери в движении** —
   подходим к каждому и проверяем, что он реально идёт, а не стоит;
6. **уклоны** — все пары узлов кратны 15°, в открытом поле не круче 38.8°
   (уступ у края площадки — законный обрыв);
7. **малые острова** — суша за 105 м в 85 направлениях, проливы есть;
8. **чанки** — видимая часть меньше общей, после разворота меняется;
9. **лодка и волны** — лодка на глубокой воде, идёт вперёд 5.2 м/с, качается,
   не вылезает на сушу.

## 2.9. Версия 0.17: полёт по зажатию, хвост черепахи, чистый спавн

`node tests/v017.mjs` — зажатый пробел реально поднимает героя (+14 м за 2 с),
Shift опускает (−14.5 м), без клавиш он висит; обычный прыжок с земли цел.
Хвост черепахи качается вокруг базового угла на ±0.05 рад (было 0.22 с выломом
в горизонталь). Спавн: ни один из 53 зверей не появляется внутри ствола, валуна
или куста, повторный спавн 60 зверей тоже чистый, далёкое блуждание обходит стволы.

## 3. Реальный браузер (headless Chromium)

`node tests/browser.mjs [url]` — открывает игру в Chromium, жмёт «Начать», проверяет,
что мир собрался без ошибок, добывает дерево, крафтит инструменты, ставит костёр и делает скриншоты
(`tests/shot-*.png`).

В этой песочнице нет системных `libnspr4/libnss3`, поэтому рядом лежат заглушки в `/tmp/nssstub`
(генерируются из списка символов бинарника) и `LD_LIBRARY_PATH` подставляется в `puppeteer.launch`.
На обычной машине с браузером это не нужно.


## 3.1. Первый запуск headless в песочнице

`bash tools/setup-headless.sh` — распаковывает Chromium и собирает заглушки `libnspr4/libnss3/libnssutil3`
в `/tmp/nssstub` (один раз на новую песочницу). После этого работают `tests/browser.mjs`, `tests/covers.mjs`
и скрипты скриншотов.

## 3.2. Скриншоты и шейдеры

```bash
cd last-shore && python3 tools/serve.py 8080 &   # сервер игры
node tests/shaderlog.mjs   # ошибки компиляции шейдеров в консоли
node tests/shots.mjs       # tests/shot-fp.png, shot-forest.png, shot-night2.png
```

## 4. Устойчивость (WebGL, safe-режим, диагностика)

`node tests/robust.mjs` — три сценария в Chromium:
1. обычный запуск,
2. запуск с `?safe=1` (лёгкая графика, без сглаживания и теней),
3. браузер без WebGL — игра должна показать причину, а не молчаливое «не работает».

Плюс проверяется панель диагностики (кнопка на стартовом экране или F1 в игре).

## Обновление острова

`npm run test:build && node tests/island-update.mjs` — проверяет оба борта лодки,
посадку и выход в море, коллизии логовищ, новых животных, облака и переключение музыки.
`node tests/shaderlog.mjs` — запуск в Chromium и проверка ошибок шейдеров (нужен сервер на :8080).

## Сервер комнат

`node tests/rooms.mjs` — создание, список, обмен положениями, изоляция комнат и выход.
Локальный запуск: `npm run serve`, затем открыть порт 8080. Чтобы играть через
интернет, сервер Node.js должен быть доступен обоим игрокам и поддерживать WSS
(например, через HTTPS-прокси). Код комнаты — латиница, цифры, дефис или `_`.
Комнаты хранятся в памяти и исчезают, когда их покидают; нет паролей или
авторизации, поэтому сервер предназначен только для доверенных тестов.
Синхронизируются положения игроков, но не общий мир или инвентарь.
Bluetooth-соединение между браузерами не реализовано.

- `node tests/menu-settings.mjs` — настройки, язык меню, список серверов и слоты сохранения (после `npm run test:build`).
- `node tests/browser-menu.mjs` — мобильное меню и слот в Chromium (нужен сервер на 8080).

## Телефонная комната и управление

`node tests/phone-features.mjs` (нужен сервер на :8080 и headless Chromium) проверяет
реальный обмен приглашением/ответом и соединение двух WebRTC-браузеров, передачу
позиций, кнопку атаки, вкладки инвентаря и туман. Прямая комната рассчитана на
двух игроков, требует обмена кодами и доступности прямого WebRTC-маршрута; при
симметричном NAT/фильтрации без TURN может не соединиться. Публичный STUN Google
используется для обнаружения адресов; общий мир не синхронизируется.

- `node tests/rock-health.mjs` (после `npm run test:build`) — HP наземных пород, слоёв и стен шахты, отображение и сохранение поверхностных камней.

- `node tests/pereplet-integration.mjs` (после `npm run test:build`) — шаг ресурсов через «Переплёт», топливо, пауза и совместимость сохранений.

- `node tests/pereplet-browser.mjs` — запуск мобильной игры, горение костра и пауза в Chromium (сервер на :8080).
