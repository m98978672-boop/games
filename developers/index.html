ПРОСТОЙ ПУТЬ

Как добавить игру

Витрина работает статически, поэтому публикация идёт через GitHub — это сохраняет исходники, историю автора и возможность проверить изменения.

01

Подготовь папку игры

Добавь в корень репозитория папку <slug>/ с игрой, обложкой, коротким README и явным указанием прав на код и материалы. На сайте она откроется по адресу `/games//`. За основу можно взять шаблон «БАЗА».

Открыть инструкцию ↗
02

Добавь одну запись в каталог

В site/community-games.json укажи название, описание, обложку, ссылку на игру и несколько особенностей. Карточка автоматически появится в корневой и исходной витрине.

Формат каталога ↗
03

Открой Pull Request

Запусти проверки, создай ветку в своём fork и открой PR. После проверки ссылок, безопасности и лицензий автор репозитория может принять изменения.

ПРО АВТОРСТВО

Твоя игра — твоя работа

Добавление игры не передаёт авторские права владельцу витрины. Укажи автора и лицензию/разрешение на размещение. В репозитории нет общей лицензии, поэтому не считай чужой код или ассеты автоматически свободными для повторного использования.

Оплата за помощь заранее не обещана: обсуди условия до начала работы и не начинай её в ожидании оплаты. Публиковать свою игру можно без вступления в команду.

ПЕРЕД ОТПРАВКОЙ

Чек-лист качества

  • Игра открывается на телефоне и компьютере без скачиваемого установщика.
  • Код, музыка, изображения и шрифты созданы тобой или разрешены для публикации.
  • В игре нет секретных ключей, скрытой телеметрии и обязательных сторонних CDN.
  • В README есть управление, требования и способ связаться с автором через публичный профиль.
  • Каталог содержит только проверенные локальные ссылки на эту папку игры.
