# Операция «Точка» — браузерный шутер

3D-шутер от первого лица на Three.js (r123). Все модели и анимации созданы с нуля без внешних моделей и CDN.

## Что внутри

- **15 анимаций × 4 варианта на модель** = 60 анимаций: бездействие, ходьба, бег, присед, прицеливание, стрельба, перезарядка, прыжок, падение, приземление, ранение, смерть, граната, ближний бой, осмотр. Варианты: стандарт, агрессив, осмотрительный, раненый.
- **ИИ боевиков**: патруль по точкам, преследование, стрельба с неточностью, присед, отход на дистанцию, фланкирование, память последнего miejsca игрока.
- **Вертеловая кукла (Verlet ragdoll)** из точек и стержней при смерти — физика падения и столкновение с полом.
- **Оптимизация без потери графики**: LOD (дальние враги без теней), пул пуль и частиц, экономное обновление теней, туман.
- **5 миссий**: уничтожение боевиков, проход к эвакуации, выживание 90 секунд, финал.

## Управление

- `WASD` — движение
- `Мышь` — взгляд
- `ЛКМ` — огонь
- `R` — перезарядка
- `C` — присед
- `SHIFT` — бег
- `P` — пауза

## Запуск

Откройте `shooter/index.html` в браузере. Никакой установки и интернета не требуется.
