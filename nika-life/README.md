# 🌸 НИКА: ЖИВАЯ (v1.1)

**Браузерный симулятор жизни с девушкой, которой управляет бесплатный локальный ИИ.**

Ника живёт в собственной **минималистичной квартире-студии**: прихожая, кухня,
гостиная, рабочий стол, спальня, ванная и санузел. Напиши ей команду по-русски —
и она переоденется за ширмой, примет ванну с пеной, ляжет спать под одеяло,
поработает за ноутбуком, поболтает с тобой, сходит в санузел, поест, поможет,
сделает зарядку или просто будет жить сама.

Тело нарисовано скелетным ригом: **223 анимации, 20 частей тела, минимум
10 отдельных клипов на каждую**.

▶️ **Играть:** [`index.html`](./index.html) (открывается двойным кликом, с `file://`, без сборки и интернета)
🌐 **На сайте Games:** https://m98978672-boop.github.io/games/nika-life/

## 🧠 Какой здесь ИИ (честно)

Это **настоящий автономный агент**, который исполняется целиком на устройстве игрока:

1. **Обучаемая модель намерений.** Однослойный softmax-классификатор (мешок слов,
   биграммы, префиксы, tf-idf-признаки) обучается прямо в браузере при запуске на
   корпусе из ~290 русских фраз и различает **26 намерений**. Модель
   **дообучается** на командах `запомни: … = …`, на исправлении последней команды
   и на списке фраз из вкладки «Обучение ИИ». Выученные фразы сохраняются в
   `localStorage` и выгружаются в JSON-файл.
2. **Слотовый парсер** достаёт из фразы вещь, цвет, часть тела, клип, локацию,
   длительность, сторону тела и жест; понимает цепочки из нескольких действий.
3. **Планировщик с функцией полезности (utility AI).** Ника сама сравнивает
   потребности (включая «комфорт») и решает: поспать, поесть, искупаться,
   сходить в санузел, поработать, помочь, поболтать, размяться или отдохнуть —
   и **сама переодевается** под занятие.
4. **Опциональная встроенная LLM браузера.** Если доступен Chrome Built-in AI
   (`LanguageModel`, локальная модель на устройстве), ИИ использует её для разбора
   свободных фраз. Если нет — работает обученная локальная модель.

### Про «обучение по интернету»

Игра **сама не делает ни одного сетевого запроса**. Обучение «по интернету»
реализовано так: ты копируешь любой текст или список фраз из сети и вставляешь
его в поле вкладки **«🧠 Обучение ИИ»** (по одной фразе на строке, можно с
разметкой `фраза = намерение`). Ника разбирает текст и переобучает нейросеть
**локально, в браузере**. Строки без разметки размечаются самой моделью.
Никаких скрытых запросов, ключей API, аккаунтов, телеметрии и платежей нет:
**0 ₽**, офлайн, `file://` и GitHub Pages.

**Ограничения:** это не облачный ChatGPT/GPT и не генеративная языковая модель:
сложная литературная импровизация и рассуждения уровня больших LLM ей недоступны.
Это обучаемый классификатор намерений + парсер + планировщик. Если нужен
автоматический захват текста по URL, это будет **явный** сетевой запрос — его
нет в этой версии сознательно, чтобы сохранить офлайн-режим и бесплатность.

## 🎮 Управление

| Действие | Как |
| --- | --- |
| Команда | строка ввода справа + <kbd>Enter</kbd> или кнопка ➤ |
| Быстрые команды | чипы под строкой ввода |
| Галерея / гардероб / тело / жизнь / обучение | вкладки слева |
| Пауза | <kbd>Пробел</kbd> |
| Помощь | <kbd>H</kbd> |
| Сохранить | <kbd>S</kbd> (автосохранение каждые 15 с) |
| Звук | <kbd>M</kbd> |
| Скорость времени | <kbd>1</kbd> / <kbd>2</kbd> / <kbd>4</kbd> или кнопки 1×/2×/4× |
| Закрыть окно | <kbd>Esc</kbd> |

На телефоне панели переключаются кнопками 💬 и ⚙ в верхней панели.
Учитывается `prefers-reduced-motion`, `lang="ru"`, сохранение в `localStorage`.

**Мир:** день длится 24 игровых часа (1 реальная секунда = 1 игровая минута на 1×).
Потребности — энергия, сытость, настроение, гигиена, форма, здоровье, комфорт,
деньги. Ника сама ходит между 7 зонами квартиры; в гардеробе 22 вещи и 8 цветов,
недостающие вещи покупаются за заработанные деньги.

## Права и ограничения

Все материалы (код, SVG-обложка, векторная графика, звук) созданы для этой игры,
лицензия и неэксклюзивное разрешение на размещение в каталоге Games — в
[`LICENSE.md`](./LICENSE.md). Внешних ассетов, шрифтов, библиотек, CDN, аналитики
и сетевых запросов нет. Прогресс и выученные фразы хранятся только в
`localStorage` браузера игрока.

> Прототип: 2D-рисовка, компактная локальная модель намерений, упрощённая экономика.
> Облачный LLM, 3D-модель и озвученная речь в эту версию не входят.
