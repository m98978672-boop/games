# Ассеты ЕВРОТРАК

Здесь лежат только сторонние файлы с явной лицензией. Всё остальное (кузов, кабина,
дорога, город, растительность) строится кодом в `src/` и файлов не требует.

## Что внутри

| Файл | Что это | Лицензия | Источник |
| --- | --- | --- | --- |
| `env/sky.exr` | ясный день, HDR-панорама 512×256 | CC0-1.0 | Poly Haven через npm `@pmndrs/assets` 1.7.0 |
| `env/dawn.exr` | рассвет | CC0-1.0 | там же |
| `env/sunset.exr` | закат | CC0-1.0 | там же |
| `env/night.exr` | ночь | CC0-1.0 | там же |
| `env/overcast.exr` | пасмурно | CC0-1.0 | там же |

`manifest.json` хранит для каждого файла путь, размер, sha256, лицензию, автора и
для каких погод/времени суток пресет предназначен. Его читает `src/core/assets.js`.

## Как обновить или добавить

```bash
node tools/fetch-assets.mjs            # докачать отсутствующее
node tools/fetch-assets.mjs --force    # перекачать всё
node tools/fetch-assets.mjs --list     # что есть в пакете
node tests/_assets.mjs                 # проверка целостности и разбора
```

Список желаемых сред задаётся в `WANTED` внутри `tools/fetch-assets.mjs`: имя файла,
погода и диапазон времени суток.

## Чего здесь не будет

Ассетов из Euro Truck Simulator 2, American Truck Simulator и других коммерческих игр.
Их нельзя переносить: это чужие авторские права. Легальные пути — CC0/CC-BY материалы
или модели, построенные по публичным чертежам и ТТХ.
