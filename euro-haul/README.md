# 🚛 ЕВРОТРАК — симулятор грузоперевозок по Европе

Полноценная браузерная игра в жанре дальнобойного симулятора: 3D-тягач с полуприцепом,
настоящая карта Европы, междугородние рейсы по дорожной сети, живой трафик, смена
суток, погода, экономика и карьера. Открывается по ссылке, ставится на телефон как
приложение не требует: ничего скачивать не нужно.

Это **самостоятельная игра в жанре** Euro Truck Simulator 2, а не копия: тягачи
вымышленной марки **AURIGA**, собственная дорожная сеть, грузы и экономика. Названия
городов и стран — настоящие, для узнаваемости карты.

▶ **Играть:** [`index.html`](./index.html) ·
[на сайте](https://m98978672-boop.github.io/games/euro-haul/)

## Что внутри

**Мир и дорога**
- 139 городов в 26 странах: Германия, Франция, Испания, Португалия, Италия, Швейцария, Австрия, Чехия, Польша, Скандинавия, Балтия, Балканы.
- Дорожная сеть строится триангуляцией Делоне по городам: маршрут прокладывается алгоритмом A*, поэтому рейс идёт через реальные промежуточные города.
- Процедурная трасса: изгибы, подъёмы и спуски, городские зоны с ограничением 50, дорожные работы с ограничением 30, знаки стран и границы.
- Живая обочина: деревья, фонари, отбойники, разметка, склады погрузки и выгрузки, АЗС и зоны отдыха вдоль маршрута.
- Смена суток (рассвет, день, закат, ночь со звёздами), шесть типов погоды: ясно, переменная облачность, пасмурно, дождь, гроза с молниями, туман. Мокрый асфальт меняет сцепление.

**Тягач и физика**
- Двигатель с кривой момента, 12-ступенчатая КПП (автомат и ручной режим), сцепление шин с дорогой, сопротивление воздуха, уклон, тормозной путь, ретардер, круиз-контроль.
- Расход топлива зависит от массы груза и стиля езды; греется охлаждающая жидкость, изнашиваются двигатель, шины и тормоза.
- Полуприцепы: тент, рефрижератор, цистерна, платформа, контейнеровоз, лесовоз — со своей геометрией.
- Вид из кабины с приборной панелью, рулём, дворниками и навигацией; камеры с капота, сзади и сверху.

**Трафик**
- Легковые, фургоны, автобусы и грузовики в обе стороны, обгоны, торможение перед попутными, ночные фары.
- Столкновения с машинами и отбойником повреждают тягач и груз, срабатывают камеры контроля скорости.

**Карьера и экономика**
- Рынок грузов: 30 видов груза, 6 категорий (обычный, хрупкий, реф, тяжёлый, ценный, ADR), масса, срок, срочность и ставка за километр.
- Уровни и опыт (кривая до 30+ уровней), шесть навыков: дальние рейсы, ценные грузы, хрупкие грузы, срочные рейсы, ADR, экономичное вождение.
- Автосалон: пять тягачей от 330 до 620 л.с., trade-in старого, тюнинг двигателя, шин и ретардера, окраска.
- Гаражи в городах, наёмные водители с пассивным доходом, три слота сохранений, 16 достижений.
- Топливо по ценам страны, ремонт, стоянки, штрафы, выплаты с вычетами за просрочку и повреждение груза.

**Интерфейс**
- Гараж-хаб с вкладками (рынок грузов, тягач, автосалон, водители, карта Европы, статистика, настройки), HUD с мини-картой, спидометром, приборами и тахометром.
- Управление клавиатурой, геймпадом (RT — газ, LT — тормоз, стик — руль, Y — камера, X — взаимодействие) и сенсором (экранные педали, руль, кнопки E и камеры).
- Поворотники с миганием и звуком, капли дождя на стекле в виде из кабины, знаки фото-контроля перед ограничениями.
- Автосохранение в `localStorage`, три профиля, настройки графики и звука.

## Как играть

1. В меню выберите **«Новая карьера»**: имя, стартовый город (Берлин, Амстердам, Париж и др.).
2. В гараже откройте **«Рынок грузов»** и примите контракт.
3. На маршруте доедьте до знака **«ПОГРУЗКА»**, остановитесь и нажмите `E` — начнётся погрузка.
4. Доветите груз до зоны **«ВЫГРУЗКА»**, остановитесь и снова `E`. Оплата придёт в кошелёк, опыт повысит уровень.
5. По пути заправляйтесь (`E` у АЗС), отдыхайте в зонах отдыха, следите за сроком: опоздание уменьшает оплату.
6. Деньги тратьте на ремонт, тюнинг, новые тягачи, гаражи и водителей — они приносят доход, пока вы за рулём.

## Технические детали

- Three.js (WebGL), чистый ES-модульный код без фреймворков; все текстуры и звук генерируются процедурно — **внешних файлов и CDN нет**, игра работает офлайн.
- Собственная физика тягача с полуприцепом: продольная динамика, ограничение бокового ускорения шинами, рыскание прицепа, уклон и сцепление.
- Дорога строится участками вокруг игрока (≈600 объектов на кадр), что держит сцену лёгкой даже на слабых устройствах.

```
euro-haul/
  index.html        разметка меню, гаража и HUD
  style.css         оформление интерфейса
  game.bundle.js    собранный бандл (готовая игра)
  src/
    main.js         игровой цикл, камера, ввод, экономика, карьера
    core/           физика, рынок грузов, сохранения, звук, математика
    world/          дорога, небо и погода, трафик, 3D-тягач, дорожная сеть
    ui/             интерфейс гаража, HUD, модальные окна
    data/           города, грузы, тягачи, достижения
  tests/            смоук-тест (jsdom) и офлайн-рендер сцены
```

### Сборка и тесты

```bash
cd euro-haul
npm install            # three, esbuild, jsdom
npm run build          # пересобрать game.bundle.js (IIFE — работает и с file://)
npm test               # интеграционный тест: меню → карьера → рейс → выплата → сохранение
npm run test:physics   # автопилот проходит 77 км маршрута, проверка устойчивости физики
npm run preview        # офлайн-рендер сцены в SVG/PNG без GPU
```

Бандл собран как обычный скрипт (IIFE), поэтому `index.html` открывается даже двойным
кликом с диска. При размещении на GitHub Pages всё работает как обычно.

`npm test` запускает игру в jsdom с заглушкой WebGL и проверяет весь путь игрока,
включая штрафы, столкновения, заправку, отдых, сохранение активного рейса и свободную поездку.

Если меняете `src/`, не забудьте `npm run build` — браузер загружает именно `game.bundle.js`.

## Ограничения и планы

- Мир — стилизованный: каждая страна представлена городами и трассой, без детальных городских кварталов и пешеходов.
- Тягачи вымышленные; официальные марки и логотипы не используются.
- В планах: развязки и кольца, погрузка задним ходом к рампе, штрафы за проезд на красный, больше типов прицепов, ночная подсветка кабины, мультиплеер не предусмотрен.
