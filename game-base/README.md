# 🛠 БАЗА — каркас всех игр (мини-игра «Светлячки»)

**БАЗА — главная игра репозитория для создателей игр.** Это самая простая игра коллекции,
и одновременно **шаблон**: все остальные игры делаются по её образцу, с тем же дизайном.
Общий визуальный язык вынесен в единый файл [`../shared/theme.css`](../shared/README.md) —
его подключает каждая игра.

▶️ **Играть:** [`index.html`](./index.html) · [витрина игр](../index.html)
📋 **Как создать свою игру на базе БАЗЫ:** [TEMPLATE.md](./TEMPLATE.md) · План: [PLAN.md](./PLAN.md) · Дизайн-система: [`../shared/README.md`](../shared/README.md)

Игра открывается двойным щелчком по `index.html` — без установки, сборки, сервера и интернета.
Всё нарисовано на `<canvas>` обычными скриптами, внешних библиотек и CDN нет.

## Мини-игра «Светлячки» (пример игрового цикла)

На тёмном поле появляются светлячки и медленно дрейфуют. **Кликай по ним, пока не погасли.**

- За светлячка: `10 × комбо` очков. Ловли подряд быстрее 3,5 с растят комбо до **×8**.
- Промах или упущенный светлячок сбрасывают комбо до ×1.
- Раунд длится **60 секунд**; рекорд и статистика сохраняются в `localStorage` (автосохранение).

## Управление

| Действие | Клавиша / мышь |
|---|---|
| Поймать светлячка | клик / тап по нему |
| Пауза | `Пробел` или кнопка ⏸ |
| Новый раунд | `R` или кнопка ↻ |
| Звук вкл/выкл | `M` или кнопка 🔊 |
| Сохранить | `S` или кнопка 💾 |
| Как играть | `H` или кнопка `?` |
| Закрыть окно | `Esc` |

## Из чего состоит БАЗА (шаблон для новых игр)

```
game-base/
├── index.html          HUD-скелет: canvas + topbar + панель + чипы + тосты + модалки
├── style.css           первая строка: @import url("../shared/theme.css"); + акцент игры
├── cover.svg           обложка 1440×810 для витрины
├── src/
│   ├── config.js       НАСТРОЙКИ ИГРЫ: id, название, акцент, правила (менять в первую очередь)
│   ├── util.js         хелперы (clamp, rand, fmt…)
│   ├── save.js         сохранение в localStorage
│   ├── audio.js        процедурный звук на WebAudio
│   ├── game.js         ИГРОВАЯ ЛОГИКА (состояние, update, клики) — главный файл для замены
│   ├── render.js       отрисовка на canvas
│   ├── ui.js           HUD: статистика, панель, тосты, модалки, клавиши — почти не трогаем
│   └── main.js         точка входа и игровой цикл
├── tests/smoke.mjs     проверка структуры: node tests/smoke.mjs
├── TEMPLATE.md         пошаговая инструкция для ИИ: «как сделать новую игру»
├── PLAN.md             план развития
└── README.md           этот файл
```

**Правило:** новая игра = копия этой папки, где меняются `config.js`, `game.js`,
`render.js`, тексты в `index.html`, акцент в `style.css` и обложка. Общий HUD
(`ui.js` + `shared/theme.css`) остаётся **одинаковым у всех игр** — поэтому все игры
выглядят и ведут себя как одна семья.
