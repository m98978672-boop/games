# PLAN — Folder OS

Эмуляция операционной системы, в которой **вместо ядра — папка, вместо процессора — папки, а всё работает на папках и файлах**. Открывается прямо в браузере, установка не нужна.

## Текущее состояние (v1.0.0)

- Виртуальная файловая система: `/bin`, `/boot`, `/dev`, `/etc`, `/home`, `/sys`, `/tmp`, `/usr`
- Ядро = папка `/sys/kernel/` с файлами-модулями (`vfs.js`, `scheduler.js`, `modules.list`)
- Процессор = папка `/sys/cpu/` с ядрами-папками `core0..core3`, в каждом файлы `load` (загрузка) и `current` (текущий процесс)
- Окна: перетаскивание, изменение размера, свёртка/развёртка, закрытие, фокус, панель задач
- Приложения: файловый менеджер, терминал, текстовый редактор, настройки, «О системе»
- Терминал: `ls`, `cd`, `pwd`, `cat`, `echo`, `mkdir`, `touch`, `rm`, `cp`, `mv`, `ps`, `exec`, `help`, `clear`, `uname`, `sysinfo`
- Диск — `localStorage`: файлы, папки и запущенные процессы сохраняются между перезагрузками

## Планируется

- Редактор прав доступа к файлам (чтение/запись по пользователям)
- Ещё встроенных «программ» в `/usr/apps/` (калькулятор, блокнот, простой браузер файлов)
- Ярлыки на рабочем столе и перетаскивание файлов между окнами
- История команд в терминале и автодополнение по Tab
- Экспорт/импорт виртуального диска в JSON-файл

## Как запустить

Открой [`folder-os/index.html`](./index.html) в любом современном браузере. Все данные хранятся в `localStorage` текущего браузера.
