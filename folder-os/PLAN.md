# PLAN — Folder OS

Эмуляция операционной системы, в которой **вместо ядра — папка, вместо процессора — папки, а всё работает на папках и файлах**. Открывается прямо в браузере, установка не нужна.

## Базовое состояние (v1.0.0)

- Виртуальная файловая система: `/bin`, `/boot`, `/dev`, `/etc`, `/home`, `/sys`, `/tmp`, `/usr`
- Ядро = папка `/sys/kernel/` с файлами-модулями (`vfs.js`, `scheduler.js`, `modules.list`)
- Процессор = папка `/sys/cpu/` с ядрами-папками `core0..core3`, в каждом файлы `load` (загрузка) и `current` (текущий процесс)
- Окна: перетаскивание, изменение размера, свёртка/развёртка, закрытие, фокус, панель задач
- Приложения: файловый менеджер, терминал, текстовый редактор, настройки, «О системе»
- Терминал: `ls`, `cd`, `pwd`, `cat`, `echo`, `mkdir`, `touch`, `rm`, `cp`, `mv`, `ps`, `exec`, `help`, `clear`, `uname`, `sysinfo`
- Диск — `localStorage`: файлы, папки и запущенные процессы сохраняются между перезагрузками

## Сделано в 3.2

- **Редактор прав доступа** (`/usr/apps/access.app`): чтение и запись по пользователям,
  правила лежат в `/etc/access.json` — это обычный файл системы, его видно в «Диске C»
  и можно прочитать в терминале командой `cat /etc/access.json`.
- **Новые программы в `/usr/apps/`**: калькулятор (четыре действия, проценты, история
  вычислений, деление на ноль не роняет окно) и блокнот (заметки — настоящие файлы
  в `/home/user/notes`, с переименованием и удалением).
- **История команд и автодополнение по Tab**: Tab дополняет и команды, и пути,
  стрелки вверх/вниз листают историю.
- **Экспорт/импорт виртуального диска** в JSON-файл (Настройки → «Диск в файл»).
  Импорт проверяет структуру и не даёт пустому файлу стереть систему.
- Все системные `alert` заменены на неблокирующие уведомления: окно ошибки больше
  не перекрывает рабочий стол на телефоне.

## Планируется

- Ярлыки на рабочем столе и перетаскивание файлов между окнами
- Простой браузер файлов внутри окна
- Горячие клавиши для окон (свернуть всё, переключение по Alt+Tab)

## Как запустить

Открой [`folder-os/index.html`](./index.html) в любом современном браузере. Все данные хранятся в `localStorage` текущего браузера.
