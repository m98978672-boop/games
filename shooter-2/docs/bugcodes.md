# Таблица кодов ошибок (000–999)

Каждому коду соответствует одна категория и одна проверка. Бот `tools/bugbot.mjs`
ссылается на эти коды в отчёте (`docs/bugbot-report.md`), поэтому по номеру сразу видно,
что именно сломалось и в какой подсистеме искать.

- всего кодов: **1000** (000–999)
- категорий: **10**
- живых детекторов: **225**

## Диапазоны

| Коды | Категория | Что проверяется |
|---|---|---|
| 000–099 | Структура проекта | файлы, разбор, подключения, офлайн, README и превью |
| 100–199 | Данные и таблицы | оружие, боевики, миссии, карты, хваты, чертежи, баланс |
| 200–299 | Карты и коллизии | геометрия уровня, коллайдеры, спавн, проходы, свет |
| 300–399 | Рендер и кадр | два прохода, фон, слои, материалы, камера, портрет |
| 400–499 | Игрок и управление | движение, выносливость, патроны, отдача, тач-стик |
| 500–599 | Бой и физика | пули, видимость, урон, гранаты и осколки, регдол |
| 600–699 | ИИ | мозг, тактики, укрытия, приказы, навигация, босс |
| 700–799 | Анимация и модели | клипы, риг, оружие, IK, позы, LOD |
| 800–899 | Интерфейс и UX | HUD, экраны, кнопки, тексты, звук, загрузка |
| 900–999 | Устойчивость | NaN, пулы, рестарт, бюджет кадра, обезьяний прогон |

Внутри диапазона: **слоты 0–19** — именованные проверки, которые бот реально выполняет;
**слоты 20–99** — слоты аудита по аспектам подсистемы (название собирается из аспекта и шага аудита).
